# 绘图多行辅助线实施计划

已在折线模板 241 和散点模板 188 的现有 RData 上验证附加辅助线后可生成 SVG、PDF 和 PNG。实现沿用现有绘图任务和下载入口，在基础图渲染成功后修改相同的 ggplot 对象，刷新结果 SVG 并保留导出使用的 RData。首批以已存在辅助线设置的折线和散点图组为准。

## 本轮基线

- goto-web 开发 HEAD 为 fbd880678f69253c47de500d2ac05b61f00993d7，包含已通过 Windows Git 获取的 origin/master 95d476d099eb0d3565ccd981ce20bd59e7b67d7c。
- goto 开发 HEAD 为 acde2183a8c3a809797c3856ba8dded4aa07211c，包含已通过 Windows Git 获取的 origin/master 0098e7a4d503eb08c0eb48f2328a0282ba4ab152。
- 旧模板的辅助线组包含 hLine、vLine、bLine 和三套样式参数。新编辑器加载这些已有值。groupId 12 和 17 的轴采用 x_column 与 y_column 标记。线型使用当前 gs_line_type 的值 1 至 6。

## 实施与测试

- [x] 前端在共用绘图设置中展示多行辅助线。每行可有多根线并设置标签、位置、颜色、线型和宽度。斜线逐根选择三种方式。采用嵌套 ObjectParam referenceLines 存储行数组。用户修改后才提交新参数。
- [x] 换数据复用列范围规则。旧记录保留已有配置。新配置的横线与竖线逐值筛除越界值，斜线按输入方式验证有效坐标。刷新历史后恢复已绘制配置。
- [x] Java 用真实 ParamContainer 测试配置读取、清空、传参和异常校验。对接既有绘图请求和 Task R 调用，以显式 NULL 关闭基础图的旧辅助线，在基础图返回成功后调用资源脚本。用户输入按 JSON 数据传递。
- [x] 独立 R 回归验证同类型多行、混合斜线、裁剪和样式，检查输出与 RData 同步。确认原始图引用的其他保存变量保留。
- [x] 按项目规范运行 Java 构建测试，启动本次动态端口服务。运行折线与散点真实 Playwright，核对预览、下载、历史恢复，复跑 Excel 换表和共用图形回归。

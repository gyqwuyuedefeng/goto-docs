# 热图矩阵识别与注释参数返修实施计划

> 使用 Superpowers 的测试先行流程，在当前隔离工作区逐项实施。

**目标：** 让热图使用 R 的检测结果控制参数，并将两侧注释颜色和图例完整传给绘图链路。

**结构：** goto/system 提供受权限保护的检测接口；goto-web 只维护界面派生状态和隐藏绘图参数；goto/common 修复现有参数生成器的空值分支。

**技术栈：** Java 17、Spring、Rserve、Vue 2、Jest、Maven。

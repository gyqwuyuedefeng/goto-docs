# 格式转换动态示意图弹窗重构设计

> 重构目标：将"按钮旁问号"改为"右上角全局入口 + Tab 切换弹窗"，提升视觉整洁度和交互统一性。

---

## 1. 背景与动机

上一版实现将示意图引导图标（❓）放在"宽转长""长转宽"选项旁，存在以下问题：

- 图标跟在文字后面，视觉杂乱、不够美观
- 两个页面的弹窗垂直居中不稳定
- 两个 SVG 无法在同一个弹窗内切换查看

本次重构将入口统一移到右上角，弹窗内通过 Tab 页签切换两个 SVG 示意图。

## 3. 入口 Icon 规格

- **样式：** 渐变紫纯圆形，白色 "?" 加粗
- **背景：** `linear-gradient(135deg, #667eea, #764ba2)`
- **尺寸：** 32px × 32px
- **阴影：** `0 2px 8px rgba(102, 126, 234, 0.3)`
- **字体：** 18px，font-weight: 700，color: #fff
- **hover：** `transform: scale(1.1)` 微放大 + 阴影加深
- **位置：**
  - `formatConvertDialog.vue`：Dialog 组件的标题栏右侧（通过 slot 或自定义标题）
  - `excelFormatConvert.vue`：页面容器右上角（`.page-header` 内或绝对定位）

## 4. 弹窗规格

### 4.1 基本属性

| 属性 | 值 |
|------|----|
| 标题 | 固定 "动态示意图" |
| 宽度 | 800px |
| 居中 | `translateY(-50%)` 垂直 + `margin: 0 auto` 水平 |
| 顶部间距 | `margin-top: 0 !important`（覆盖 Element UI 默认） |
| 关闭方式 | 点击 ✕ / 按 ESC / 点击遮罩层 |

### 4.2 Tab 页签

- **Tab 1：** "宽转长动态示意图" → 展示 `wide-to-long-guide.svg`
- **Tab 2：** "长转宽动态示意图" → 展示 `long-to-wide-guide.svg`
- **默认选中：** 始终 Tab 1（与当前转换类型无关）
- **样式：** 使用 Element UI `<el-tabs>` 组件，`type="card"` 或自定义下划线样式
- **激活态：** 下划线颜色使用 Icon 同款渐变紫 `#667eea`

### 4.3 内容区

- **图片：** `max-width: 100%`、`height: auto`、`display: block`
- **滚动：** 内容区 `max-height: calc(100vh - 120px)`、`overflow: auto`
- **兜底：** SVG 加载失败 → 显示 "示意图加载失败，请稍后重试"（居中灰色文字，min-height: 180px）

## 5. 组件数据与逻辑

### 5.1 Data

```js
data() {
  return {
    // ...
    guideDialogVisible: false,
    guideImageLoadError: false,
    guideActiveTab: 'w2l'  // 当前激活的 Tab：'w2l' | 'l2w'
  }
}
```

### 5.2 Computed

```js
computed: {
  // 根据 guideActiveTab 返回当前 Tab 对应的 SVG 资源
  currentGuideImage() {
    return this.guideActiveTab === 'l2w' ? longToWideGuide : wideToLongGuide
  }
}
```

### 5.3 Methods

```js
methods: {
  openGuideDialog() {
    this.guideActiveTab = 'w2l'       // 始终默认宽转长
    this.guideImageLoadError = false
    this.guideDialogVisible = true
  },
  closeGuideDialog() {
    this.guideDialogVisible = false
  },
  onGuideTabChange(tab) {
    this.guideActiveTab = tab         // 切换 Tab 时更新
    this.guideImageLoadError = false  // 重置错误状态
  },
  onGuideImageError() {
    this.guideImageLoadError = true
  }
}
```

## 6. 模板结构

### 6.1 formatConvertDialog.vue

Icon 放在 Dialog 组件的标题栏右侧。由于项目使用封装的 `<Dialog>` 组件，需要在 `<Dialog>` 的 title slot 中放置 Icon：

```html
<Dialog :title="'Excel格式转换'" ...>
  <template slot="title">
    <span>Excel格式转换</span>
    <span class="guide-entry-icon" @click="openGuideDialog">?</span>
  </template>
  ...
</Dialog>
```

如果 `<Dialog>` 组件不支持 title slot，改为在 Dialog 内部顶部绝对定位放置 Icon。

### 6.2 excelFormatConvert.vue

Icon 放在页面 header 右上角：

```html
<div class="page-header">
  <h1 class="title">长宽格式转换工具</h1>
  <span class="guide-entry-icon" @click="openGuideDialog">?</span>
</div>
```

### 6.3 弹窗模板（两个文件共用）

```html
<el-dialog
  :visible.sync="guideDialogVisible"
  title="动态示意图"
  custom-class="format-guide-dialog"
  width="800px"
  :close-on-click-modal="true"
  :close-on-press-escape="true"
  :show-close="true"
  @close="closeGuideDialog"
>
  <el-tabs v-model="guideActiveTab" @tab-click="onGuideTabChange">
    <el-tab-pane label="宽转长动态示意图" name="w2l">
      <div class="format-guide-body">
        <img v-if="!guideImageLoadError" :src="wideToLongGuide" alt="宽转长动态示意图" class="format-guide-image" @error="onGuideImageError">
        <div v-else class="format-guide-error">示意图加载失败，请稍后重试</div>
      </div>
    </el-tab-pane>
    <el-tab-pane label="长转宽动态示意图" name="l2w">
      <div class="format-guide-body">
        <img v-if="!guideImageLoadError" :src="longToWideGuide" alt="长转宽动态示意图" class="format-guide-image" @error="onGuideImageError">
        <div v-else class="format-guide-error">示意图加载失败，请稍后重试</div>
      </div>
    </el-tab-pane>
  </el-tabs>
</el-dialog>
```

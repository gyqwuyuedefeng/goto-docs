# 统计工作空间改版完成总结

## 结果摘要

工作空间和统计方法页已实现并通过本地回归。数据预处理显示入口按钮。当前 R 版本的直接 RData 计算合同尚未通过，兼容计算使用已确认数据生成的 Excel。前后端和文档保留在各自任务分支，等待后续集成。

## 原因与目标

本次根据《统计.html》和配套截图，将统计分析的主数据导入统一到工作空间。用户确认预处理先提供入口。验收要求包括自定义名称、变量概况与编辑、数据集复用、真实计算和导出。

## 设计决策

- 用同一账号锁发布新的数据集版本。统计概况提供版本标识，提交时比对后固化输入文件。
- 用实际 R 输出生成类别标签和工作簿。保留 base/data.RData 和 base/variable_info.xlsx，兼容旧目录中的已就绪数据。
- 删除操作在变量表中移除所选变量，确认前可撤销。保存保留源工作簿，并对剩余变量重新编号。

## 实际变更

- goto-web 顶部菜单为「统计」。目录增加工作空间与预处理入口。工作空间提供卡片命名、分页、勾选移除、拖拽调序、重新编辑和处理摘要。
- goto-web 共享统计方法页以数据概况代替主数据 Excel 上传和样本预览。变量角色按方法切换，概况随选择更新角色数。
- goto 新增数据集改名和概况接口，确认可重新发布版本并识别作者返回的结构化摘要。旧版分布和变更可从实际确认过的元数据补足。

## 验证结果

- 前端 54 项统计单测、4 项回归汇总脚本测试通过，修改的前端源文件 ESLint 检查通过。
- Java 使用受管 WSL 包装器运行 Dataset*Test 与 Statistics*Test。61 项通过，零失败、零错误，最终验证进程退出 0，日志有 BUILD SUCCESS。
- 本次前端、manager 与 task 分别在回环端口 23095、22115 与 20277 验收。独立 MySQL、Redis Stream 和本机 Rserve 使用本次合成数据与专用目录。
- `npm run test:statistics -- local` 退出 0。真实 Playwright 核对改名、移除中间列、有序类别拖拽、修改后保存及保留期。11 种方法实际计算和下载 15 份工作簿。描述性统计的固定样本均值核对为 6.25。
- `statisticsVisibility.playwright.cjs` 的管理角色和普通账号两次验证通过。普通账号访问概况接口被拒绝。
- 已恢复并比对临时登录页的原始字节、SHA-256 和 Git 差异。本次五个服务端口均已释放，合成数据目录已清理。

## 偏差、风险与遗留

- 本地 gotoStat 0.1.0 的描述性统计在接收同一数据的 Excel 时成功，传入确认产物 RData 报 vctrs_error_subscript_oob。当前按经实测的 Excel 兼容路径计算。RData 直传仍需当前方法的公开可执行接口及新版包验证。
- Eclipse 的旧依赖在 WSL 直连超时，通过同一官方来源的 Windows 通道获取，使用临时 Maven 文件仓库继续构建。首次非交互包装命令在报告成功后返回 143，原因待确认。改用前台终端重新执行，最终 Java 进程退出 0。
- Playwright 首轮导入专项卡在类别列表的文本定位。以列表项内的精确类别文本修正定位，最终整套用例退出 0。
- GitNexus 的变更扫描将共享提交链路标记为高影响，实际差异集中在数据集、统计提交和验证。权限和 11 种方法已用真实浏览器覆盖。生产站点未参与此次验证。
- 基线工作区另有任务改动。本次未合并和发布，保留 `worktrees/goto-web/feat/060-统计工作空间改版`、`worktrees/goto/feat/040-统计工作空间改版` 和 `worktrees/goto-docs/docs/044-统计工作空间改版`。

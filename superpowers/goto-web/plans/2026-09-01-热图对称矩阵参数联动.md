# 热图对称矩阵参数联动实施计划

> **面向执行 Agent：** 必须逐项按 TDD 执行；每个任务先完成失败测试，再写最小实现并运行对应测试。

**目标：** 让热图根据行、列变量集合的对称性自动约束样式、显示正确的聚类 tab，并按热图样式显示正确的单元格设置 tab。

**架构：** 仅扩展既有 `heatmapModify.js`：一个纯集合比较函数和一个统一刷新函数。刷新函数复用现有过滤后标记列、设置查询、分组查询和设置持久化工具；`publicFunction.js` 只增加首次加载回调注册。

**技术栈：** Vue 2、Element UI、Jest、Lodash、Playwright。

## 全局约束

- 变更集 ID 固定为 `CS-20260901-6c70c1b0-5ed0-4e44-9c4d-2f21f5431b4f`。
- 只修改热图前端代码与对应单元测试；不写数据库。
- `heatmapStyle` 的字典值固定为 `full`、`upper`、`lower`、`triangle`、`invtriangle`、`split`。
- Playwright 必须使用本次动态端口、`reuseExistingServer: false`，结束后关闭服务并确认端口释放。

- [ ] **步骤 1：实现无序集合比较。**

```js
function isSymmetricMatrix(rowValues, columnValues) {
  const rowValueSet = new Set(rowValues || [])
  const columnValueSet = new Set(columnValues || [])
  if (rowValueSet.size !== columnValueSet.size) return false
  return Array.from(rowValueSet).every(value => columnValueSet.has(value))
}
```

- [ ] **步骤 2：实现最小刷新函数。**

```js
const HEATMAP_STYLE_VALUES = ['full', 'upper', 'lower', 'triangle', 'invtriangle', 'split']

function refreshHeatmapMatrixSettings(commonParams) {
  const rowValues = obtainRowValues(commonParams)
  const columnValues = obtainColumnValues(commonParams)
  const symmetric = isSymmetricMatrix(rowValues, columnValues)
  const heatmapStyle = localFindFromTopParamSettingsList('heatmapStyle', commonParams)
  const diagonal = localFindFromTopParamSettingsList('diagonal', commonParams)

  setHeatmapStyleDisabledIndexes(commonParams, heatmapStyle, symmetric)
  if (!symmetric && heatmapStyle && heatmapStyle.value !== 'full') heatmapStyle.value = 'full'
  if (diagonal) diagonal.visible = symmetric
  setGroupVisible(commonParams, symmetric, '聚类设置')
  setGroupVisible(commonParams, !symmetric, '行聚类设置', '列聚类设置')
  refreshHeatmapCellGroups(commonParams, heatmapStyle && heatmapStyle.value)
  PublicFunctions.updateSettingsByPlotGroupIdAndPlotTypeId(collectChangedSettings(...), commonParams)
}
```

其中 `obtainRowValues` 从 `row` 头信息的 `chooseColumnAllList` 汇总值；`obtainColumnValues` 从 `col` 头信息的 `columnName` 汇总值。`setHeatmapStyleDisabledIndexes` 以 `heatmapStyle.list` 的实际顺序产生禁用索引，且在对称时置为空数组。`setGroupVisible` 使用 `localFindGroupFromTopParamSettingsListByName`。所有新增或修改的代码须有中文注释，说明集合比较与 UI 约束的业务原因。

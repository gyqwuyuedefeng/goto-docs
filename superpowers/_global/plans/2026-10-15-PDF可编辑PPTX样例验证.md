# PDF原生可编辑PPTX样例验证 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从用户提供的业务PDF生成文字、16个节点、27条流带分别可编辑的独立PPTX样例，并用实际PowerPoint检验外观和修改持久性。

**Architecture:** 只解析本业务样例遇到的PDF对象，将其按绘制顺序映射为Open XML原生对象，绕过已失真的LibreOffice PDF导入。转换脚本和输出只放本次临时目录；PowerPoint验证独立于转换器，不能以结构测试替代实际渲染。不支持的效果必须明确报错或记录未通过，不静默栅格化。

**Tech Stack:** Python 3、pypdf、python-pptx、lxml、Pillow、numpy、Windows PowerPoint COM、已有Poppler渲染工具。

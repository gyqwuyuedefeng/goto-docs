# 公开绘图模板真实回归实施计划

目标是让当前公开的每个绘图模板在上线前完成一次真实分析和结果下载。使用 Node.js、Playwright 和项目现有的 Vue、system、task、Redis Stream、Rserve 链路。

- 通过浏览器首页的真实目录发现公开模板。管理员可见的隐藏项不进入清单。可传入实时数据库公开 ID 清单，校验页面覆盖；子集运行只用于定位问题。
- 从各模板卡片进入，登记页面新建的绘图 ID，使用应用的默认输入或明确的补充用例。点击开始分析，观察提交、本次记录的 WebSocket 完成消息和可读结果。对同一记录点击下载并检查文件或多格式包。
- 用纯输入目录测试样例链路，将历史成图排除在输入之外。缺样例、必选标记未满足、任务失败、页面空白和真实下载失败均在对应阶段报告，继续检查其他模板。最终报告区分完整运行和子集运行。
- 在 `goto-web/tests/e2e/plotPublishedRegression.playwright.cjs` 保存执行用例。使用 `node --check` 检查脚本。使用本次前端、system、task、隔离 Redis DB 1 和本机 Rserve 串行验证，先验证一个公开模板，再执行当前完整目录。应用测试创建的记录通过应用接口清理，下载和报告保存到本次临时目录。
- 三个工具箱能力仍属于上线前回归范围。复用图片转换用例，拼图和长宽互转用具有可核对内容的样例补齐覆盖。逐项记录验证状态。
- 本次 Windows Git 同步后，前端 `origin/master` 为 `95d476d099eb0d3565ccd981ce20bd59e7b67d7c`，工作起点 `fbd880678f69253c47de500d2ac05b61f00993d7`。后端 `origin/master` 为 `0098e7a4d503eb08c0eb48f2328a0282ba4ab152`，运行起点 `acde2183a8c3a809797c3856ba8dded4aa07211c`。两者保留本地主线已经存在的功能和测试提交。

## 运行方法

1. 使用 Node.js 20、Chromium 和 `unzip`。核对待发布的前后端提交，按项目本地测试规则启动本次前端、system、task，核对 home 数据库、隔离 Redis、本机 Rserve 及样例输入路径。启动的 JAR 从待验证提交构建后复制到本次临时目录并记录摘要，避免共享构建目录被并行构建替换。按待发布版本准备每个模板的完整 `Upload` 工作簿，包括列标记生成的 `file-mark-*.xlsx` 等计算输入。每个模板保留空的 `Result` 目录，用户结果目录从空目录开始。
2. 从 home 数据库按当前 `app_plot_group.show=1 AND app_plot_type.show=1` 生成模板 ID 字符串的 JSON 数组。脚本将其与页面真实目录比对，发现遗漏或额外模板时退出。
3. 提供 `PLOT_BASE_URL`、`PLOT_SYSTEM_URL`、`PLOT_RUNTIME_DIR`、`PLOT_PUBLIC_TEMPLATE_IDS`、`PLOT_REUSE_EXISTING_SERVER=false`、`PLOT_PLAYWRIGHT_MODULE`、`PLOT_CHROMIUM_EXECUTABLE` 和运行时 `PLOT_LOGIN_CODE`。从本次 goto-web 工作区执行：

```bash
node --check tests/e2e/plotPublishedRegression.playwright.cjs
node tests/e2e/plotPublishedRegression.playwright.cjs
```

脚本也接受模板 ID 作为末尾参数，便于单独重跑。报告中的 `fullRun` 会标识全量覆盖。以本次临时目录下的 `report.json` 核对每项的阶段、下载和清理状态。任何失败均使进程返回非零，任务终态未知时保留记录并停止本轮。测试之后按项目规范关闭本次服务并恢复登录页。

## 工具箱回归

使用相同服务与运行时变量，另外设置 `PLOT_TOOL_PDF_INPUT` 为本轮公开绘图下载得到的 PDF 文件。绘图回归完成后串行运行：

```bash
node tests/e2e/plotToolsRegression.playwright.cjs
```

拼图用两张上传的 SVG 验证任务受理和真实下载。长宽格式转换用两份小工作簿验证两个方向，回读结果并核对全部单元格。图片格式转换从 PDF、SVG 分别提交页面提供的八种输出，逐项记录转换和下载结果。全部 19 项需要有明确结果。可传入 `merge`、`wide`、`long`、`svg`、`pdf` 运行指定子集。

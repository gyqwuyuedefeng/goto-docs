# 抖音分享链接视频下载 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现一个可测试的抖音分享链接下载 CLI，并用它验证 Codex Task Orchestrator 的真实执行与证据链。

**Architecture:** CLI 调用小型应用服务；应用服务依赖 `DownloadAdapter` 协议，生产适配器封装 `yt-dlp`，测试注入假适配器。链接校验、下载和 JSON 表达分离，默认测试不访问真实抖音。

**Tech Stack:** Python 3.12+、uv、pytest、yt-dlp、标准库 argparse/dataclasses/pathlib。

## Global Constraints

- 只处理公开、无 DRM、用户有权访问的抖音视频。
- 不实现网页、登录绕过、验证码、去水印、代理池、批量或其他站点。
- Cookie 只允许仓库外普通文件，且内容不得进入日志、Prompt、提交或测试证据。
- 默认自动化不得访问真实抖音。
- 所有实现遵循 TDD；每个任务先看到预期 RED，再实现 GREEN。
- Codex 不得直接修改 `main` 或自行提交；提交由 Worker 在测试通过后创建并带当前 `Task-ID`。

```python
URL_PATTERN = re.compile(r"https?://[^\s]+")

def extract_douyin_url(share_text: str) -> str:
    matches = URL_PATTERN.findall(share_text)
    if len(matches) != 1:
        raise DownloadError("INVALID_SHARE_TEXT", "分享内容必须包含且仅包含一个抖音链接")
    parsed = urlsplit(matches[0].rstrip(".,，。!！"))
    host = (parsed.hostname or "").lower()
    if host != "douyin.com" and not host.endswith(".douyin.com"):
        raise DownloadError("UNSUPPORTED_HOST", "仅支持抖音分享链接")
    return parsed.geturl()
```

- [ ] **Step 3: 实现协议、结果模型与服务校验**

```python
class DownloadAdapter(Protocol):
    def download(self, url: str, output_dir: Path, cookie_file: Path | None) -> DownloadResult: ...

class DownloadService:
    def __init__(self, adapter: DownloadAdapter) -> None:
        self._adapter = adapter

    def download(self, url: str, output_dir: Path, cookie_file: Path | None) -> DownloadResult:
        output_dir.mkdir(parents=True, exist_ok=True)
        result = self._adapter.download(url, output_dir, cookie_file)
        if not result.output_path.is_file() or result.output_path.stat().st_size <= 0:
            result.output_path.unlink(missing_ok=True)
            raise DownloadError("EMPTY_DOWNLOAD", "下载结果为空")
        return replace(result, bytes=result.output_path.stat().st_size)
```

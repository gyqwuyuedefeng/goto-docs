# 结果摘要

桑基图分析完成后的内部 SVG 同步不再误弹“上传成功”；结果 HTML 自带的 `Download SVG` 按钮已隐藏；页面统一下载可导出当前拖拽和缩放后的 SVG。代码在本地 `goto-web` 与 `goto` 的 `master`，尚未推送远端。

# 原因与目标

全局上传响应提示把内部 SVG 同步当成用户上传；iframe 隐藏逻辑只覆盖网络图按钮；后端 SVG 下载分支未包含桑基图组 15。目标是修复这三项并用真实浏览器、真实分析和下载文件验证，不改变用户主动上传的提示。

# 设计决策

只对内部 SVG 上传请求关闭成功提示，失败仍按原逻辑提示；在现有 iframe 隐藏逻辑中增加桑基图按钮选择器；后端复用现有 SVG 导出分支处理组 15。没有新建导出协议或修改机密 R 包。

# 实际变更

- `goto-web`：内部 SVG 同步和下载前上传使用静默成功提示选项；隐藏两类 HTML 内置下载按钮；端到端脚本验证真实分析、交互、按钮和统一下载。脚本在本地多套服务竞争 Redis 通知时可从已持久化结果恢复页面状态；此恢复只服务于验收。

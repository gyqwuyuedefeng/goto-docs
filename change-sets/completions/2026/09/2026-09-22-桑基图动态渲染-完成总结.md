# 结果摘要

桑基图已在本地 `goto-web/master` 改为 D3.js + 原生 SVG 动态渲染，同一 SVG 用于页面展示和下载。浏览器隔离验收确认节点拖拽、连线实时跟随、悬停提示与高亮、缩放，以及下载后 SVG 与当前布局一致。完整后端绘图链路尚未通过，故本变更集当前终态为 `blocked`，不能称为完整验收完成；未推送远端。

# 原因与目标

原桑基图仅展示静态 SVG，用户要求参照网络图的交互方式，实现节点拖拽、连线跟随、悬停反馈、缩放，并下载拖拽后的当前布局；同时参考生产模板的参数、字典和文件列标记关系，保留网络图行为。验收标准包括真实浏览器中从登录、上传、标记、分析到交互和下载的完整链路。

# 设计决策

采用桑基图专用 D3 渲染器和最小的交互结果注册入口，页面与下载共用运行中的 SVG；保留网络图原有 iframe 结果路径。节点拖拽开始时提升其 SVG 绘制层级，避免同列节点遮挡。没有改写受保护的 R 包或扩大为通用图形框架。浏览器用例的 `SANKEY_FRONTEND_ONLY=1` 仅隔离后端失败，明确不能替代完整链路验收。

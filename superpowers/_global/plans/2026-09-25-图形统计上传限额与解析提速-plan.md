# 图形／统计上传限额与解析提速 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 图形／统计上传前后端统一限制为 20,000,000 字节，并消除大表插列的平方级搜索，保持整表编辑。

**Architecture:** 前端直接使用的 `Uploader` 默认限制设为 20 MB；后端在六个业务上传处理类进入保存与解析前调用同一个大小校验器。`HandsontableUtils.addColumn` 按行下标遍历，避免反复 `indexOf`。

**Tech Stack:** Vue 2、Jest、Java 17、Spring Boot 3、JUnit 5、Maven 安全包装器。

## Global Constraints

- `Change-Set-Id: CS-20260925-6ccfe78f-d470-4f95-a4b5-8c73c0c23231`；所有提交用中文消息及该 trailer。
- 机密 R 包目录和同源副本禁止读取、索引、构建、测试内部实现。
- Maven 仅用 WSL 安全包装器；Java 新增和修改代码及测试需详细中文注释。
- 前后端边界为 `size <= 20_000_000` 允许，`size > 20_000_000` 拒绝。
- 保留上传后整表立即可编辑、现有接口格式及非图形／统计上传限制。

## File Structure

- `goto-web/src/views/components/uploader/uploader.vue`：直接上传入口的默认单文件限制。
- `goto/system/src/main/java/com/freedom/model/file/upload/impl/PlotTypeUploadSizeLimit.java`：六类图形／统计上传共用的大小判断及错误消息。
- `goto/system/src/main/java/com/freedom/model/file/upload/impl/{PlotTypeImageUpload,PlotTypeFileUpload,PlotTypeExampleFileUpload,StatisticsUpload,FileMarkFileMergeUpload,PlotTypeFileMergePreviewUpload}.java`：在 `init()` 首先调用大小判断。
- `goto/system/src/test/java/com/freedom/model/file/upload/impl/PlotTypeUploadSizeLimitTest.java`：20 MB 边界与六个入口拒绝大文件。
- `freedom-public/common-utils/src/main/java/com/freedom/util/HandsontableUtils.java`：按下标一次处理一行。
- `freedom-public/common-utils/src/test/java/com/freedom/util/HandsontableAddColumnTest.java`：CSV 整表结果和大表处理时间回归。

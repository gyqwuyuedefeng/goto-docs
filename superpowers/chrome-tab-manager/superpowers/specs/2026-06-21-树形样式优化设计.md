# 树形样式优化设计

**日期：** 2026-06-21

## 目标

优化多级分组树形视图的视觉效果，修复 favicon 加载问题。

## 变更

### 1. 置顶图标 → 蓝色圆点

- 将分组标题 `★` 替换为蓝色圆点标记
- CSS 类 `.group-pin-dot { color: #3b82f6; font-size: 10px; margin-left: 4px; }`

### 2. 嵌套层级优化

- 移除 `.group.nested .group-header` 的 `border-left` 竖线
- 子分组用 `margin-left: 24px` + 淡背景 `#f8fafc` + 圆角区分层级
- 子分组内网页行增加 16px 左缩进
- 保持 `.nested-level-X` 的 `padding-left` 策略，改为子分组容器级别生效

### 3. Favicon 修复

- `getFaviconUrl` 当前固定拼接 `https://${domain}/favicon.ico`，对非标准 favicon 路径会 404
- 新增硬编码映射：`platform.deepseek.com` → `https://fe-static.deepseek.com/platform/favicon.svg`
- 在 `schema.js` 中增加 `FAVICON_OVERRIDES` 映射表，`getFaviconUrl` 优先查表

## 变更文件

| 文件 | 变更 |
|---|---|
| `src/sidepanel/sidepanel.js` | 替换 ★ 为圆点 HTML |
| `src/sidepanel/sidepanel.css` | 移除竖线、新增嵌套淡背景、圆点样式 |
| `src/shared/schema.js` | 新增 FAVICON_OVERRIDES 映射表 |

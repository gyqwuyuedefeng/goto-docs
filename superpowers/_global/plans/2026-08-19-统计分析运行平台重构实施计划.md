## Frozen HTTP Contract

### 公共响应原则

- 成功列表沿用项目公共响应包装，但 `data` 中的业务字段按本节固定。
- 校验错误返回 `400`，资源不存在或不属于当前用户统一返回 `404`，乐观锁/确认数量变化返回 `409`。
- `409` 草稿响应的 `data` 为 `{ "code": "DRAFT_VERSION_CONFLICT", "latestDraft": DraftDetail }`。
- 文件接口不使用公共 JSON 包装；预览 Blob/下载使用安全的 `Content-Type` 与 RFC 5987 文件名。

```json
{
  "catalogVersion": "2026.08.19.1",
  "categories": [{
    "key": "descriptive",
    "name": "描述性统计与数据分布",
    "methods": [{
      "methodKey": "descriptive-statistics",
      "name": "描述性统计",
      "description": "...",

    }]

}
```

方法详情增加：

{

  "name": "ROC 分析",
  "catalogVersion": "2026.08.19.1",
  "roles": [{
    "key": "ID",
    "name": "样本 ID",
    "minColumns": 0,
    "maxColumns": 1,
    "dataTypes": ["TEXT", "NUMBER"],
    "help": "..."
  }],
  "parameters": [{
    "key": "direction",

    "type": "SINGLE_SELECT",

    "options": [{"value": "auto", "label": "自动"}],

### 草稿 DTO

`GET/PUT /api/statistics/drafts/{methodKey}` 的 `DraftDetail`：

```json
{
  "methodKey": "roc",
  "catalogVersion": "2026.08.19.1",
  "version": 6,
  "source": {
    "fileId": "uuid",
    "originalName": "data.xlsx",
    "mediaType": "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
    "size": 1234,
    "sha256": "...",
    "sheetName": "Sheet1",
    "rowCount": 20,
    "columnCount": 4,
    "columns": [{"key": "c0", "name": "sample", "inferredType": "TEXT"}],
    "previewRows": [["S1", 1.2, "A"]]
  },
  "columnRoles": {"ID": ["c0"], "VARIABLE": ["c1"], "GROUP": ["c2"]},
  "parameters": {"direction": "auto"},
  "updatedAt": "2026-08-19T12:00:00+08:00"
}
```

- `PUT` 请求为 `{ "version": 6, "catalogVersion": "...", "columnRoles": {...}, "parameters": {...} }`。
- `POST source` 使用 multipart 字段 `file` 和必填文本字段 `version`；成功返回新的 `DraftDetail`。
- `DELETE source` 使用查询参数 `version`；成功返回新的 `DraftDetail`。
- 上传支持 `.xlsx`、`.xls`，且只接受可解析的首个可见工作表；重复列头返回定位明确的 `400`。

### 运行 DTO

- `POST /api/statistics/runs`：`{ "methodKey", "draftVersion", "submissionId", "commonNoticeUUID" }`。
- `POST /api/statistics/runs/{runId}/rerun`：`{ "submissionId", "commonNoticeUUID" }`。
- 两者成功为 `202`；相同用户和 `submissionId` 重试返回同一 `RunDetail`。
- `POST /api/statistics/runs/{runId}/cancel` 无请求体，返回当前 `RunDetail`。
- `GET /api/statistics/runs` 参数为 `methodKey`、`status`、`createdFrom`、`createdTo`、`page`、`size`。

`RunDetail` 固定核心字段：

```json
{
  "runId": "uuid",
  "methodKey": "roc",
  "methodName": "ROC 分析",
  "status": "SUCCEEDED",
  "parentRunId": null,
  "catalogVersion": "2026.08.19.1",
  "adapterVersion": "1",
  "gotoStatVersion": "0.1.0",
  "parameters": {},
  "columnRoles": {},
  "sourceManifest": [],
  "inputManifest": [],
  "failure": null,
  "results": [{
    "fileId": "uuid",
    "displayName": "result.xlsx",
    "mediaType": "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
    "size": 1234,
    "sha256": "...",
    "previewKind": "EXCEL",
    "sheetNames": ["Sheet1"],
    "partial": false
  }],
  "createdAt": "...",
  "startedAt": "...",
  "finishedAt": "...",
  "durationMillis": 1200,
  "expiresAt": "..."
}
```

- 失败对象为 `{ "stage": "EXECUTION", "code": "R_EXECUTION_FAILED", "message": "脱敏信息" }`。
- Excel 预览查询参数固定为 `sheet`、`page`、`size`，默认 `page=0,size=100`，最大 200；响应为 `{ "sheetName", "sheetNames", "columns", "totalRows", "page", "size", "rows" }`。
- PDF/图片 preview 返回 Blob；未知文件 preview 返回 `415`，仍可 download。

### 保留策略 DTO

- 策略为 `{ "mode": "DAYS|FOREVER", "retentionDays": 3|null, "version": 1, "updatedBy", "updatedAt" }`。
- `PUT /api/statistics/admin/retention` 请求必须携带 `version`。
- 重新计算预览请求为 `{ "mode", "retentionDays" }`，响应为 `{ "previewToken", "affectedCount", "calculatedAt" }`。
- 应用请求为 `{ "previewToken", "expectedAffectedCount" }`；再次计算数量不一致返回 `409` 和最新 `affectedCount`。

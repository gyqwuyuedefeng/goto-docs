# 堆叠柱状图环形连接线联动实施计划

> **供代理执行：** 必须逐项按测试先行执行；每项均使用复选框追踪。

**目标：** 当堆叠柱状图样式为 `circular_y` 时，强制将 `addConnectingLine` 关闭并禁用；切换至其他样式仅解除禁用。

**架构：** 在既有 `stackBarModify.js` 中新增一个只负责连接线状态的辅助函数。该函数由样式切换、首次加载及文件标记保存后的现有入口调用，复用参数查找与 `updateSettingsByPlotGroupIdAndPlotTypeId` 持久化机制。

**技术栈：** Vue 2、JavaScript、Jest、现有参数联动模块。

## 全局约束

- 参数名必须是模板 `app_plot_type.id = 135` 已确认的 `addConnectingLine`，关闭值必须为字符串 `"FALSE"`。
- `circular_y` 以外的样式不得把该值自动恢复为 `"TRUE"`。
- 仅在从非 `"FALSE"` 值强制改为 `"FALSE"` 时持久化，避免重复请求。
- 不新增后端接口、数据库字段或模板变更。
- 新增、修改的 JavaScript 测试必须使用中文注释解释业务意图。

### 任务 2：实现并接入最小联动函数

**文件：**

- 修改：`goto-web/src/constant/modify/stackBarModify.js`

**接口：**

- 输入：`commonParams`，从其中获取样式 `type` 与参数 `addConnectingLine`。
- 输出：在 `circular_y` 时强制关闭并禁用连接线；在其他样式解除禁用。

- [ ] **步骤 1：在样式工具函数附近新增连接线联动函数**

```js
/**
 * 环形（Y轴弯曲）不支持连接线，需关闭并锁定该参数；其他样式只恢复可编辑性。
 * 仅在需要将既有开启值迁移为关闭值时持久化，避免重复请求。
 *
 * @param {Object} commonParams - 当前图形参数上下文
 */
function connectingLineModify(commonParams) {
  const connectingLineSetting = localFindFromTopParamSettingsList(
    'addConnectingLine',
    commonParams
  )
  if (!connectingLineSetting) {
    return
  }

  const circularY = getStyleValue(commonParams) === STACK_BAR_STYLE_CIRCULAR_Y
  connectingLineSetting.disabled = circularY
  if (circularY && connectingLineSetting.value !== 'FALSE') {
    connectingLineSetting.value = 'FALSE'
    PublicFunctions.updateSettingsByPlotGroupIdAndPlotTypeId(
      [connectingLineSetting],
      commonParams
    )
  }
}
```

- [ ] **步骤 2：接入既有三条生命周期路径**

```js
function styleModify(commonParams) {
  stackBarStyleFacetReconcile(commonParams)
  styleSettingsVisibleModify(commonParams)
  connectingLineModify(commonParams)
  radialStripPositionModify(commonParams)
  labelSettingsModify(commonParams)
}

function stackBarFirstLoadModify(commonParams) {
  stackBarStyleFacetReconcile(commonParams)
  styleSettingsVisibleModify(commonParams)
  connectingLineModify(commonParams)
  radialStripPositionModify(commonParams)
  labelSettingsModify(commonParams)
}
```

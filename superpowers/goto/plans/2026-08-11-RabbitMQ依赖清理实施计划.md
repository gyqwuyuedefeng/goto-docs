# RabbitMQ 依赖清理实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 在不改变当前 Redis Stream、Redis 限流与防重复提交逻辑的前提下，移除 `goto` 对 RabbitMQ 的运行时依赖和配置，并把 `freedom-public` 中仍有兼容价值的 RabbitMQ 能力改为显式引入依赖后才生效的可选能力。

**架构：** `goto` 的最终应用依赖树完全不再包含 Spring AMQP/RabbitMQ；`eladmin-common` 限流链路只保留 Redis；`common-utils`、`common-ttl-log`、`common-thread` 中的 RabbitMQ 兼容代码保留，但 AMQP 依赖标记为 optional，自动配置使用类路径条件保护。`common-r` 和 `common-thread-r` 删除无实际使用的 AMQP 依赖。

**技术栈：** Java、Spring Boot、Spring Conditional、Spring Data Redis、Redis Stream、JUnit 5、Maven。

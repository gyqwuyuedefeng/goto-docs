# 热图对称矩阵参数联动设计

## 目标

在热图数据的行变量与列变量代表同一去重集合时，自动显示适用于对称矩阵的参数；否则限制为全矩阵并显示独立的行、列聚类配置。用户改变热图样式时，单元格设置 tab 必须同步切换。

## 已核对的运行数据

- `app_plot_group` 中热图图组为 `id=13`。
- `app_plot_type.id=1` 是 `group_id=13` 的热图模板；其 `param_settings` 中的相关设置名称为 `heatmapStyle`、`diagonal`、`聚类设置`、`行聚类设置`、`列聚类设置`、`单元格设置`、`单元格设置（上三角）`、`单元格设置（下三角）`。
- 字典 `gs_heatmap_style`（`dict_id=62`）的值为 `full`、`upper`、`lower`、`triangle`、`invtriangle`、`split`；`split` 的展示文本是“双矩阵对角分割”。
- 字典 `gs_diagonal`（`dict_id=63`）的值为 `none`、`upper`、`lower`。

## 最小实现

实现保留在现有热图修改模块，不新增组件、接口或数据模型。

1. 在 `heatmapModify.js` 增加对称矩阵判断函数：从现有 `row`、`col` 标记的过滤后头信息取得行变量值和列变量名，分别去重；集合大小一致且每个行变量均存在于列变量集合时为对称矩阵。比较不依赖原始顺序。
2. 在同一模块增加一个统一的刷新函数，修改现有设置对象并通过 `updateSettingsByPlotGroupIdAndPlotTypeId` 持久化：
   - 非对称：`heatmapStyle.disabledIndexList` 禁用除 `full` 外的字典项；若当前值已禁用，回退为 `full`；隐藏 `diagonal`；隐藏“聚类设置”，显示“行聚类设置”和“列聚类设置”。
   - 对称：清空 `heatmapStyle.disabledIndexList`；显示 `diagonal`；显示“聚类设置”，隐藏“行聚类设置”和“列聚类设置”。
   - `heatmapStyle === 'split'`：隐藏“单元格设置”，显示“单元格设置（上三角）”和“单元格设置（下三角）”。其他值执行相反的显示规则。
3. 复用 `findFilteredHeaderInfoListByGroupIdAndKey`、`localFindFromTopParamSettingsList`、`localFindGroupFromTopParamSettingsListByName` 和 Vue 的 `$set`，与已有热图和堆叠柱状图的参数联动模式保持一致。
4. 在行、列文件标记保存后的热图回调、热图样式变更回调和热图首次加载回调中调用该刷新函数；在 `publicFunction.js` 注册热图首次加载回调。这样新建、编辑以及重新打开保存图形三种路径行为一致。

## 不做的事

- 不修改数据库模板或字典数据。
- 不新增后端 API、Vue 组件或全局状态。
- 不改变非热图图组的参数行为。

## 验收

1. 单元测试覆盖无序、重复元素的对称判断，以及集合不一致的非对称判断。
2. 单元测试覆盖非对称时仅 `full` 可选、对角线隐藏、聚类 tab 切换及样式回退。
3. 单元测试覆盖 `split` 与非 `split` 的三个单元格设置 tab 切换。
4. Playwright 使用一次性空闲端口启动前端；临时使用公众号验证码登录页，以验证码 `666888` 登录，完成对称和非对称热图页面的可见性与禁用态验证，然后关闭服务并还原登录页文件。

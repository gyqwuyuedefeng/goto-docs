# 图形上传双阶段遮罩实施计划

**目标：** 图形上传的页面遮罩覆盖顺序执行的上传和表格读取两个请求。

**架构：** 侧栏发送上传开始与第一步失败事件；绘制页持有页面遮罩状态并等待表格读取 Promise；表格组件返回原有请求 Promise。通用上传器继续负责原有错误提示。

**技术栈：** Vue 2、Element UI、Jest、ESLint。

## 范围约束

- 仅修改图形绘制页的上传链路，不修改统计上传和后端接口。
- 保持 `/file/upload` 后调用 `/api/plotType/obtain_file_setting_handsontable` 的顺序。
- 保持 20,000,000 字节限制和现有表格编辑行为。

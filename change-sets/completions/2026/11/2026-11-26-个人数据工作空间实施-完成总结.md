# 个人数据工作空间实施总结

## 结果摘要

个人数据工作空间已发布到 GOTO 生产站点。用户可以导入 Excel，选择工作表，确认变量类型与类别顺序，然后在全部 11 个统计方法中复用数据集。管理页面可以配置保留时间、每账号容量、单文件上限和数据集数量。

前端、Java 后端、两个 R 包和安装脚本均已推送各自的主分支。合入后在隔离环境通过 11 个方法和 15 份结果下载的真实 Playwright 验收。生产复验通过数据集导入、变量确认、描述性统计、两样本检验、两份 Excel 校验和管理设置读取。

## 原因与目标

统计分析原先需要在方法页面逐次提交工作簿。首版把工作簿和变量确认保存在账号自己的数据空间，保留有效重复观测和缺失值信息，验收覆盖真实上传、分析、下载及直接上传的已有行为。

## 设计决策

按账号隔离数据集。后端以账号锁协调配额、到期清理和快照创建，使用原子切换发布就绪版本。统计任务复用现有接口和运行快照。R 数据准备和变量更新由现有 Rserve 调用固定入口执行。配额按账号生效，管理页面的默认值为 7 天、100 MB、20 MB、10 个。

## 验证结果

- 按 Java 17 和 WSL Maven 安全入口构建真实发布包。定向测试共 64 项，零失败、零错误。前端生产构建、3 项前端单元测试及两个安装脚本用例通过。
- 在独立 MySQL、Redis、前端和两个 Java 服务上顺序运行 `datasets.playwright.cjs` 和 `datasetsMethods.playwright.cjs`。两项进程退出码均为 0，全部 11 个方法和 15 份 Excel 下载通过。相关距离使用 6 列，PLS 使用不标准化设置。
- 此次功能的直接上传回归通过 65 个真实浏览器场景。描述性统计与同版 R 定值样本逐表逐格核对。数据集管理设置走真实授权接口，账号隔离、并发配额与到期由 Java 用例验证。
- 生产先在独立的 R 包库验证准备、零列／单列／两列确认和单列描述性统计 Excel。切换后两个 Java 服务均为运行状态且重启计数为 0，匿名数据集请求返回 401。
- 生产通过真实登录打开统计目录并读取 11 个已发布模板。Playwright 上传含两个工作表的 Excel，确认重复行、缺失值与有序类别顺序，复用到描述性统计和两样本检验。两份真实下载均经 ExcelJS 检查，描述性统计变量 `Value` 的样本数是 8，均值是 6.25。合成测试数据集已删除。
- 真实生产管理页面显示 7 天、100 MB、20 MB、10 个，授权接口返回值一致。生产首页和 5 个引用资源的实际响应与发布包 SHA-256 一致。

## 偏差、风险与遗留

- 本地首次 Rserve 环境缺少数据集接口和摘要依赖的导出声明。更新引用包并重装后，真实 R 样本复跑通过。确认单列时出现的维度简化和后续描述性统计变量名丢失，已通过独立样本和浏览器下载回归验证。
- 共用 MySQL 验收时曾有任务已产出有效 Excel，结果登记返回 `RESULT/INVALID_FILE`。失败记录的写入实例待确认。随后使用独立 MySQL、Redis 和任务文件目录复跑，全部方法通过。
- 使用 Vue Router 3.0.2 时，页面直传的数字模板 ID 导致确认后返回工作台超时。入口按字符串传递后通过。四个监督模型固定样本自动识别出的有序类别缺少默认顺序，补齐后全部确认、拟合与独立验证通过。
- Java 发布构建首次缺少内部制品，使用可核对的前置依赖源码组成临时 Maven reactor。第一次打包在 WSL 挂载盘上发生 JAR 重命名失败，关闭前一轮本任务 JVM，并将生成目录移至 WSL 原生磁盘后重建通过。前端为处理挂载盘读文件异常使用了本次构建进程的临时适配。
- 本次生产冒烟执行了两个真实方法，另外九个方法由合入后的隔离端到端回归覆盖。通用预处理页面属于后续设计范围。
- 本次隔离验收的五个端口均已释放，测试登录页已按 SHA-256 和 Git 差异复核恢复。本次生产浏览器与临时登录资料已清理。前后端工作区 `feat/038-数据工作空间` 和 `feat/057-数据工作空间` 已在确认合入、复验、保存证据后删除，分支保留。Java 构建记录与工作区已存在的索引保存在发布临时目录。

# 统计工作空间改版

统计首页提供上传数据和预处理两个入口。预处理按钮显示功能暂未开放。工作空间用卡片显示数据集，可自定义名称。类型确认页分页展示作者提供的变量信息，勾选移除的是变量，原始上传及已受理的统计快照仍可用于各自的流程。有序类别支持拖拽，键盘可在同一列表完成调序。再次编辑在独立版本保存，账号权限、配额和过期规则适用于每个版本。

统计方法页选用工作空间数据，数据概况提供变量角色编辑并统计各角色的变量列数。角色按方法校验，分析时保存实际分组、变量和 ID 选项。统计方法计算请求只使用已就绪的个人数据集。单样本的逐变量假设表作为方法的辅助参数沿用其校验。

新版导入按作者接口使用 `base/imported_data.RData`、`base/record.RData` 和 `base/variable_info.xlsx`。确认成功后以 `base/data.RData` 和对应变量概况为准。旧工作空间文件在确认时补齐最新版包所需的记录和路径，保留此前已清理的数据与有序类别。预处理功能当前仅展示入口。

统计提交在账号锁中固化确认版本的 RData 与校验表，并分别核对摘要。任务以 `base/data.RData` 为应用适配层的 inputFile。适配层用 R 的 load 读取实际数据，按照已校验的样本和列角色选择数据，通过 gotoStat 的公开 inputData 参数完成分析。配对对齐、稳健缩放和监督模型受试者 ID 处理使用对应的已校验转换结果。当前包的通用文件读取器会把 RData 读成一列文本，故使用内存入口保留原生列和变量名。

浏览器验收以真实计算和下载为准，并对照 11 次实际运行中的 RData 快照与任务脚本。最新版包的结果说明表路径在本地隔离环境通过安装包的实际资源映射。

# 原因与目标

原桑基图仅展示静态 SVG，用户要求参照网络图的交互方式，实现节点拖拽、连线跟随、悬停反馈、缩放，并下载拖拽后的当前布局；同时参考生产模板的参数、字典和文件列标记关系，保留网络图行为。验收标准包括真实浏览器中从登录、上传、标记、分析到交互和下载的完整链路。

# 设计决策

最初采用桑基图专用前端 D3 渲染器，但用户随后明确要求与网络图完全一致，故改为复用网络图的 R HTML → iframe → 当前 SVG 导出链路。后端只扩展 groupId 15 的 HTML 读取，前端注册表停止选择旧渲染器；HTML 缺失时沿用网络图的静态图片回退。旧 D3 组件文件暂保留但不进入页面展示链路。没有读取或改写受保护的 R 包源码，也没有扩建通用图形框架。

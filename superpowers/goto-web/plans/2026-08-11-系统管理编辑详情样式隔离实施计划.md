# 系统管理编辑详情样式隔离实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不修改共享用户组件和业务脚本的前提下，统一精修两个系统管理页面的全屏编辑详情。

**Architecture:** 两个系统页模板提供唯一的 `.management-detail-shell` 上下文，并给 `FileSettings`、`ParamSettings` 实例添加管理端 class；`_management-pages.scss` 通过 scoped `::v-deep` 只覆盖该上下文内的共享组件 DOM。共享组件本身不增加 prop、不导入管理端样式。

**Tech Stack:** Vue 2、Element UI、SCSS、Jest、Playwright MCP。

## Global Constraints

- 两个目标页面 `<script>`、接口、事件、权限、字段、ref 和数据流不得改变。
- `src/views/goto/components/paramSettings.vue`、`fileSettings.vue`、`form/plotSetting/**` 与 `src/views/goto/plot/**` 不得修改。
- 新样式必须从 `.goto-settings-page .management-detail-shell` 上下文进入，不得写入全局主题。
- 不新增依赖，不复制共享组件。

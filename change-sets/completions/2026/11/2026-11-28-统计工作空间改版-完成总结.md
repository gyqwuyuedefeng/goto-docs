# 统计工作空间改版完成总结

## 结果摘要

工作空间、统计方法页和 RData 计算接入已完成本地验收。预处理显示入口按钮。11 种统计方法已通过真实 Playwright。前后端与文档保留在各自任务分支。

## 原因与目标

本次根据《统计.html》和配套截图，将统计分析的主数据导入统一到工作空间。用户确认预处理先提供入口。验收要求包括自定义名称、变量概况与编辑、数据集复用、真实计算和导出。

## 设计决策

- 用同一账号锁发布新的数据集版本。统计概况提供版本标识。提交时校验版本并同时固化 RData 和验证表。
- 用作者最新版导入接口生成 base 下的 RData 和变量概况。旧数据重新确认时由当前包生成规范记录，并保留已经清理的数据及类别。
- 删除操作在变量表中移除所选变量，确认前可撤销。保存保留源工作簿，并对剩余变量重新编号。

## 实际变更

- goto-web 顶部菜单为「统计」。目录增加工作空间与预处理入口。工作空间提供卡片命名、分页、勾选移除、拖拽调序、重新编辑和处理摘要。
- goto-web 共享统计方法页以数据概况代替主数据 Excel 上传和样本预览。变量角色按方法切换，概况随选择更新角色数。
- goto 新增数据集改名和概况接口，确认可重新发布版本并识别作者返回的结构化摘要。旧版分布和变更可从实际确认过的元数据补足。task 加载本次运行的 base/data.RData，再通过公开 inputData 接口计算，验证阶段使用原有已校验的列和行。

## 验证结果

- 前端 54 项统计单测和 4 项回归汇总测试通过。Java 最终相关测试覆盖 61 项，零失败、零错误，Maven 退出 0。
- 联调使用 gotoBase `0a7826bf52b0928b4cb0a08806df38fb332bb941` 和 gotoStat `1c1ef9f0cc3a540466d4ba16b4cdbec5466f8517` 的独立安装。验证前端、manager、task、MySQL、Redis 和 Rserve 的专用运行路径与实际端口。
- `npm run test:statistics -- local` 退出 0。真实浏览器验证改名、删除中间变量、有序类别拖拽、修改后重新保存和保留期。11 种方法计算并下载 15 份工作簿，每次成功提交均核对实际 RData 路径。描述性统计保留变量名 Value，固定样本均值为 6.25。
- 管理角色和普通用户的两次 Playwright 权限验证通过。用旧包生成的合成数据集在新包下可重新确认，保持样本值和类别顺序。
- 已比对登录页恢复前后的 SHA-256。前端、manager、task、Rserve 临时代理、MySQL 和 Redis 的本次端口均已释放。清理独立 R 库、资源映射和本次合成数据。

## 偏差、风险与遗留

- 上一阶段 RData 直传卡在通用读取器。实际对照显示读取器把 RData 读成名为 RDX3 的单列文本。应用适配层用 R load 获取数据，采用公开内存接口，11 种方法实际验收通过。
- 新版包读取结果说明的绝对路径指向作者环境，安装包中确实包含该工作簿。本地隔离验收将该路径临时映射到包内资源，验收后已删除临时映射。生产环境使用的实际资源路径仍需在发布验收时核对。
- 单变量的第一次计算保留了正确均值，但普通 data.frame 使新版包输出列名 data。以真实输入对照确认应保留 tibble 结构，复跑已核对列名和结果。
- Eclipse 的旧依赖在 WSL 直连超时，通过同一官方来源的 Windows 通道获取，使用临时 Maven 文件仓库继续构建。首次非交互包装命令在报告成功后返回 143，原因待确认。改用前台终端重新执行，最终 Java 进程退出 0。
- Playwright 首轮导入专项卡在类别列表的文本定位。以列表项内的精确类别文本修正定位，最终整套用例退出 0。
- GitNexus 的变更扫描将共享提交链路标记为高影响，实际差异集中在数据集、统计提交和验证。权限和 11 种方法已用真实浏览器覆盖。生产站点未参与此次验证。
- 基线工作区另有任务改动。本次未合并和发布，保留 `worktrees/goto-web/feat/060-统计工作空间改版`、`worktrees/goto/feat/040-统计工作空间改版` 和 `worktrees/goto-docs/docs/044-统计工作空间改版`。

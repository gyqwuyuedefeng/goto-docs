# 热图联动与分析提示返修实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复热图单元格大小、对角线标签和单元格标记 Tab 显隐，允许实际数值列切换连续映射，并使画图失败通知只展示串行化 JSON 中的 `msg`。

**Architecture:** 复用 `heatmapModify.js` 现有集中派生状态刷新流程，使首载、参数变更和列标记保存共用一套规则。映射弹窗仅放宽“非空内容全部是有限数值”的列；画图失败消息只在 `draw.vue` 的 WebSocket 通知边界解包。

**Tech Stack:** Vue 2、Element UI、Jest、现有 Vue CLI、Playwright。

## Global Constraints

- 仅修改 `/mnt/f/IdeaProjects/goto-software/goto-web`，不改数据库模板、goto 后端或 R 包。
- `cellTypeA === "default"` 只隐藏 `cellSizeA`，不改变 `cellTypeB/cellSizeB`。
- `limitType` 现有行为保持不变；普通文本离散列仍不能切换连续映射。
- 画图失败消息解包仅作用于画图页 `status === 5`，不改全局 Toast 和其他页面。
- 所有生产代码修改都必须先有能按预期失败的回归测试。
- Playwright 使用动态端口和 `reuseExistingServer=false`，临时登录页在验收后必须按 SHA-256 恢复。

```js
supportsContinuousMapping(headerInfo) {
  if (!headerInfo) return true
  if (headerInfo.numberColumn) return true
  const values = Array.isArray(headerInfo.chooseColumnAllList)
    ? headerInfo.chooseColumnAllList
    : []
  const nonEmptyValues = values.filter(value =>
    value !== null && value !== undefined && String(value).trim() !== ''
  )
  return nonEmptyValues.length > 0 && nonEmptyValues.every(value =>
    Number.isFinite(Number(String(value).trim()))
  )
}
```

- [ ] **Step 3: 实现画图失败消息局部解包**

在 `draw.vue` methods 中加入：

```js
normalizeAnalysisFailureMessage(message) {
  if (typeof message !== 'string') return message
  try {
    const parsed = JSON.parse(message.trim())
    if (
      parsed &&
      typeof parsed === 'object' &&
      !Array.isArray(parsed) &&
      typeof parsed.msg === 'string' &&
      parsed.msg.trim() !== ''
    ) {
      return parsed.msg.trim()
    }
  } catch (error) {
    // 普通错误文本不是协议 JSON，原样交给通知组件。
  }
  return message
}
```

将 `notifySimple` 的消息实参改为：

```js
data.status === 5
  ? this.normalizeAnalysisFailureMessage(data.msg)
  : data.msg
```

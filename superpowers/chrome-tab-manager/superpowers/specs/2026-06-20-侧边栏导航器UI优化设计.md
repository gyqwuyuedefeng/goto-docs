# 侧边栏导航器 UI 优化设计

## 背景

当前 Chrome 标签侧边栏管理器已经完成初始版本，可以在 Chrome Side Panel 中保存和打开分组网页。用户试用后反馈：

- 整个插件目前显示在浏览器右侧，希望使用方式变成左侧导航器。
- 当前顶部按钮占用空间较多，像表单工具面板，不像网页导航工作台。
- 网页列表没有显示 favicon，识别效率不够高。
- 网页行直接显示“开”“删”按钮，含义不够清晰，也让列表显得拥挤。
- 删除等危险操作应放到右键菜单或更多菜单中。
- 列表区域需要支持折叠，折叠后只显示网页 icon。
- 列表区域需要支持拖拽调整宽度。
- 插件需要一个更好看的 `G` Logo，`G` 是用户名字首字母。

## 目标

本次迭代将插件从“按钮 + 列表面板”优化为“左侧 Side Panel 导航器”：

- 明确插件适配 Chrome 左侧 Side Panel 使用方式。
- 插件内部改为左侧竖向工具栏 + 可折叠导航区域。
- 使用圆形 `G` 徽章作为插件 Logo。
- 树形列表显示 favicon、标题和域名。
- 点击网页行直接打开或切换网页，不再显示“开”按钮。
- 删除、重命名、恢复、复制 URL、移动分组等操作进入右键菜单或 `⋯` 更多菜单。
- 支持树形列表模式和图标墙模式。
- 图标墙按分组分区显示所有网页，并把常用网页置顶。
- 支持分组置顶、网页常用标记。
- 支持导航区域折叠，折叠后只显示网页 favicon。
- 支持拖拽调整导航区域宽度，并持久化宽度。
- 支持 3 个预设主题：默认浅色、深色专业、G 徽章渐变。

## 非目标

- 不尝试通过扩展强制修改 Chrome Side Panel 的浏览器级左右位置。
- 不实现复杂自定义色盘，只提供预设主题。
- 不实现多窗口之间不同 UI 偏好的独立配置。
- 不实现网页内容预览或 iframe 嵌入。
- 不改变已有“点击打开真实网页”的核心行为。

## Chrome 左侧 Side Panel 边界

Chrome Side Panel 容器显示在左侧还是右侧，属于 Chrome 浏览器级设置。插件需要在 README 和界面提示中说明：如果用户希望整个插件显示在浏览器左侧，需要在 Chrome 的侧边栏设置中将 Side Panel 位置切到左侧。

插件内部不依赖容器位置强行布局，而是适配“左侧导航工作台”的使用方式：

```text
浏览器窗口
├─ 左侧：Chrome Side Panel 中的插件导航器
└─ 右侧：Chrome 主标签页中的真实网页
```

## 总体布局

插件内部采用三层结构：

```text
Chrome Side Panel
├─ 竖向工具栏
│  ├─ G 徽章 Logo
│  ├─ 保存当前页
│  ├─ 保存当前窗口
│  ├─ 保存标签组
│  ├─ 树形列表模式
│  ├─ 图标墙模式
│  ├─ 导入
│  ├─ 导出
│  ├─ 主题设置
│  └─ 折叠/展开
└─ 可折叠导航区域
   ├─ 搜索框
   ├─ 树形列表模式
   └─ 图标墙模式
```

竖向工具栏固定在插件最左侧，宽度建议 48px。导航区域位于工具栏右侧，默认宽度建议 340px，支持拖拽调整。

## G 徽章 Logo

Logo 使用圆形徽章样式：

- 主体是大写字母 `G`。
- 圆形背景与当前主题联动。
- 默认浅色主题下使用深色文字和浅色边框。
- 深色专业主题下使用深底和高亮描边。
- G 徽章渐变主题下使用渐变背景和白色 `G`。

第一版优先使用 CSS 实现徽章，不引入额外图片资产。这样可以同时用于：

- 竖向工具栏顶部。
- 折叠态占位。
- favicon 加载失败时的默认占位图标。

## 树形列表模式

树形列表用于管理大量分组和网页。

展示结构：

```text
▾ 智能体 · 11        ⋯
  [favicon] Rancher
            rancher.huoshi.cloud
  [favicon] 投研智能体
            irlm-pc.hsmap.com

▸ 工作台 · 8          ⋯
▸ 文档资料 · 15        ⋯
```

网页行显示：

- favicon。
- 网页标题。
- 域名。

网页行不直接显示完整 URL，完整 URL 通过 hover tooltip、右键菜单或更多菜单查看。点击网页行本身执行打开动作：当前窗口已有相同 URL 标签则切换，没有则新建标签并激活。

## 菜单行为

删除等危险操作不再直接暴露为行内按钮。分组和网页都提供 `⋯` 更多菜单，并支持右键菜单。

分组菜单：

```text
恢复到当前窗口
恢复到新窗口
重命名分组
置顶分组 / 取消置顶
导出该分组
删除分组
```

网页菜单：

```text
打开网页
复制 URL
标记常用 / 取消常用
移动到分组
删除网页
```

右键菜单和 `⋯` 菜单内容保持一致。右键菜单服务熟练用户，`⋯` 菜单保证操作可发现。删除分组和删除网页都保留二次确认。

## 图标墙模式

图标墙模式用于快速打开网页。它按分组分区显示所有网页，同时把常用网页置顶。

展示结构：

```text
常用
[icon] Rancher   [icon] 投研智能体   [icon] 工作台

智能体
[icon] Rancher   [icon] 投研智能体   [icon] 产业招商大脑

文档资料
[icon] Chrome Docs   [icon] GitHub   [icon] Wiki
```

规则：

- 所有网页都按原分组显示。
- 被标记为常用的网页额外出现在顶部“常用”区。
- 常用区只是快捷入口，不从原分组移除。
- 点击 icon 打开或切换网页。
- hover 显示标题和域名。
- 右键 icon 显示网页菜单。

## 分组置顶与网页常用

分组支持置顶：

- 置顶分组在树形列表和图标墙中都排在普通分组前面。
- 多个置顶分组之间仍按原 `sortOrder` 排序。
- 普通分组之间也继续按 `sortOrder` 排序。

网页支持常用：

- 常用网页在图标墙顶部“常用”区展示。
- 原分组中的网页项仍保留，不移动。
- 折叠态优先显示常用网页 icon。

## 折叠态

折叠态用于在侧边栏较窄时保留快速入口。

完整态：

```text
竖向工具栏 + 导航区域
```

折叠态：

```text
竖向工具栏 + icon-only 快捷列
```

折叠态显示规则：

1. 优先显示常用网页 icon。
2. 如果没有常用网页，显示排序靠前的网页 icon。
3. icon hover 显示标题和域名。
4. 点击 icon 打开或切换网页。
5. 右键 icon 显示网页菜单。

折叠态固定宽度建议 72px，不显示网页标题和 URL。

## 拖拽宽度

导航区域右边界提供拖拽手柄：

- 最小宽度建议 240px。
- 默认宽度建议 340px。
- 最大宽度建议 520px。
- 折叠宽度固定建议 72px。
- 用户拖拽后的宽度保存到 `chrome.storage.local`。
- 刷新 Side Panel 后恢复上次宽度和折叠状态。

## 主题

第一版提供 3 个预设主题：

- `light`：默认浅色。
- `dark`：深色专业。
- `gGradient`：G 徽章渐变。

主题影响：

- 背景色。
- 边框色。
- 选中态。
- G 徽章。
- 工具栏按钮 hover 状态。

主题偏好保存到 `chrome.storage.local`。

## 数据结构调整

在现有状态结构上增加 `ui`、`group.pinned`、`item.favorite`、`item.faviconUrl` 字段。

```js
{
  ui: {
    mode: "tree",
    collapsed: false,
    navWidth: 340,
    theme: "light"
  },
  groups: [
    {
      id: "group_001",
      name: "智能体",
      pinned: false,
      sortOrder: 1,
      expanded: true,
      items: [
        {
          id: "item_001",
          title: "Rancher",
          url: "https://rancher.huoshi.cloud/login",
          source: "page",
          favorite: false,
          faviconUrl: "https://www.google.com/s2/favicons?domain=rancher.huoshi.cloud&sz=32",
          sortOrder: 1
        }
      ]
    }
  ]
}
```

兼容旧数据：

- 缺少 `ui` 时补默认 UI 偏好。
- 缺少 `group.pinned` 时补 `false`。
- 缺少 `item.favorite` 时补 `false`。
- 缺少 `item.faviconUrl` 时根据 URL 域名生成。

## Favicon 生成

第一版使用 URL 域名生成 favicon：

```text
https://www.google.com/s2/favicons?domain=<domain>&sz=32
```

如果 URL 无法解析或 favicon 加载失败，显示圆形 `G` 默认占位图标。

## 测试与验收

自动测试：

- `normalizeState` 能补齐 `ui`、`group.pinned`、`item.favorite`、`item.faviconUrl`。
- favicon 生成函数能从 URL 提取 domain。
- 分组排序时置顶分组排在普通分组前。
- 常用网页能被筛选到图标墙常用区。
- UI 偏好更新能持久化，包括 `mode`、`collapsed`、`navWidth`、`theme`。
- 删除逻辑仍只删除本地记录，不关闭 Chrome 标签页。

手工验收：

- README 说明如何把 Chrome Side Panel 放到浏览器左侧。
- 插件内部不再显示顶部大按钮网格。
- 竖向工具栏显示圆形 `G` 徽章。
- 树形列表显示 favicon、标题、域名。
- 网页行不再显示“开”“删”按钮。
- 点击网页行能打开或切换真实网页。
- 分组和网页的 `⋯` 菜单可用。
- 右键菜单可用。
- 删除分组和删除网页有二次确认。
- 图标墙按分组分区显示所有网页。
- 常用网页显示在图标墙顶部。
- 折叠态只显示网页 icon。
- 拖拽宽度后刷新仍保持。
- 3 个主题可切换并保存。

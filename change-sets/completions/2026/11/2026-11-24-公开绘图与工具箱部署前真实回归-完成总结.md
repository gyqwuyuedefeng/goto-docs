# 公开绘图与工具箱部署前真实回归完成总结

## 结果摘要

完成 61 个公开绘图模板、19 项工具箱能力的 Playwright 真实回归。公开绘图全量通过 59 个，失败 2 个。工具箱通过 14 项，失败 5 项。发布验收未通过。回归脚本已在独立前端分支提交，保留工作区供复验。

## 原因与目标

本次验证用户选择任一公开模板后能否完成分析、看到本次生成的图形并下载模板当前默认格式。同步验收拼图、宽转长、长转宽，以及图片转换界面提供的 PDF、SVG 输入与输出组合。范围按 home 实时公开目录和页面可见性核定，共六个公开图形分组。

## 设计决策

- 用 Playwright 登录并从真实卡片进入，关联模板 ID、绘图 ID、提交响应、WebSocket 终态、可见的新图和浏览器下载。每轮从实时目录确定范围，下载内容和失败阶段写入本轮报告。
- 本次样例采用与发布环境逐文件 SHA-256 一致的 151 份工作簿，包括列标记生成的计算输入。测试记录的输出目录从空目录创建。
- 桌面浏览器访问本次动态端口的前端和 system。真实计算由本次 task 经隔离 Redis DB 1 调用本机 Rserve。系统端口分别用 23685、20971 完成两轮环境验证。前端与 task 的全部端口见验证记录。
- 测试发现任务终态未知时先查询当前记录状态，无法确认结束则保留记录并停止本轮。工具的下载按实际任务 ID 校验，误标格式和下载错误均记录为失败。

## 实际变更

- goto-web 增加 `tests/e2e/plotPublishedRegression.playwright.cjs` 与 `tests/e2e/plotToolsRegression.playwright.cjs`。代码提交 `0f1299b0167b6773565170922a980070d86e6996`。

## 验证结果

- Java 17 使用 WSL 安全入口打包，`package -Dmaven.test.skip=true` 退出 0 且完整日志包含 BUILD SUCCESS。此命令用于准备运行产物。绘图与工具实际验证使用前端 `fbd880678f69253c47de500d2ac05b61f00993d7`、后端 `acde2183a8c3a809797c3856ba8dded4aa07211c`。
- 完整发布样例回归覆盖 61 个模板，59 个通过、2 个失败、0 个未运行。韦恩图组 12/12，饼环图组 9/9，堆叠柱状图组 15/15，散点图组 8/8，桑基图组 6/7，折线图组 9/10。59 份确实下载的默认 PDF 均通过独立解析和页面内容检查。
- 桑基图模板 291 的 task 在 09:49:51 写入成功终态，浏览器在 90 秒内没有收到完成通知，未进入结果下载。相同发布样例在新启动的隔离环境单独复验通过。延迟原因待确认。工具执行前的新版录制同时通过 54 的出图和下载。
- 折线图模板 276 在全量与定向两次均返回分析失败，R 执行的长度校验报告实际为 0，要求长度为 1 或 3。内部根因待确认。
- 工具箱 14/19 通过。宽转长与长转宽下载工作簿均核对列名和数据。图片转换 12/16 通过，SVG 转 TIFF、JPEG 的下载文件实际为 PNG，PDF 转 TIFF、JPEG 显示可下载后发起下载请求均返回 HTTP 500。上传两张 SVG 的拼图任务已受理，随后返回任务失败。
- 补充桑基图自定义输入验收确认鼠标移动节点改变了布局，下载的 SVG 保留移动结果。额外的 PDF 中文节点文本提取断言失败，未据此判断视觉显示是否缺字。
- 汇总登记过的 129 条绘图记录均经应用接口清理，数据库只读回查残留为 0。本次启动的本地服务和隔离 Redis 均已关闭，全部 12 个动态端口核验释放。临时登录页原始 SHA-256 一致，暂存与未暂存差异均为空。本次共享挂载临时目录和认证材料已清理。
- 两份正式 Playwright 脚本通过 Node 语法和 Git 差异检查。脚本用途、环境参数与运行方式见实施计划。

## 偏差、风险与遗留

- 初始隔离 Redis 缺少应用要求的认证及本地验证码映射，导致 Java 启动和浏览器登录分别失败。为本次隔离实例配置认证并登记测试账号映射后恢复，未动共享 Redis。
- 首轮样例混用了本机旧数据与补齐的发布原始输入，且缺少一部分列标记文件。首轮 35/61 只作为排查证据。后续按发布目录完整工作簿摘要重新准备数据并复跑。空 Result 目录在首个试跑发现存储依赖后补齐。
- 回归中并行构建清理了共享 manager JAR，随后新登录因序列化服务类无法加载失败。通过已核验同一后端提交的发布制品启动独立副本，恢复工具箱及定向复验。计划补充了独立保存待测制品的步骤。
- 登录后首页可能已经发出目录请求，脚本将监听提前到登录提交之前。Excel 选列按钮使用带图标的控件，改用控件文本定位后两个方向真实通过。
- 当前主线在测试期间推进了多行辅助线等相关代码。当前主线尚未运行本轮公开绘图全量回归。保留未合并前端工作区 `/mnt/f/IdeaProjects/goto-software/worktrees/goto-web/test/050-公开绘图回归`，暂未满足合并验证和删除条件。

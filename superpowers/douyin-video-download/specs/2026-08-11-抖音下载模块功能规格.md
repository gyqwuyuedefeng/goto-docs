## 2. 功能范围

实现一个 Python 模块和命令行工具。用户传入抖音分享文字或单个分享链接，工具提取唯一 URL，校验域名，调用可替换下载适配器保存公开视频，并输出稳定 JSON。

首版仅支持：

- `https://www.douyin.com/...`
- `https://v.douyin.com/...`
- 公开、无 DRM、用户有权访问的视频
- 单链接、单视频、单次前台执行

首版不实现网页、批量任务、下载历史、账号登录、验证码、去水印、代理池、转码、私密视频或其他站点。

## 3. 输入

命令：

```bash
uv run douyin-video-download "<分享文字或链接>" --output-dir <目录> [--cookies <仓库外文件>]
```

约束：

- 分享文字必须恰好包含一个 HTTP(S) URL。
- URL 主机必须是 `douyin.com` 的精确子域或根域，拒绝相似后缀。
- 输出目录必须可创建或已存在且可写。
- Cookie 为可选项；只接受仓库外的普通文件，不跟随符号链接。

## 4. 输出

成功退出码为 `0`，标准输出只包含一个 JSON 对象：

```json
{
  "status": "COMPLETED",
  "video_id": "123456",
  "title": "示例视频",
  "output_path": "/absolute/path/example.mp4",
  "bytes": 1024
}
```

失败退出码为 `2`，标准输出只包含：

```json
{
  "status": "FAILED",
  "error_code": "INVALID_SHARE_TEXT",
  "message": "分享内容必须包含且仅包含一个抖音链接"
}
```

不得输出 Cookie、下载直链、堆栈、环境变量或其他秘密。

## 5. 错误码

| 错误码 | 场景 |
|---|---|
| `INVALID_SHARE_TEXT` | 没有 URL、多个 URL 或 URL 语法无效 |
| `UNSUPPORTED_HOST` | 不是允许的抖音域名 |
| `INVALID_OUTPUT_DIR` | 输出目录不可创建或不可写 |
| `INVALID_COOKIE_FILE` | Cookie 文件缺失、为符号链接或位于仓库内 |
| `DOWNLOAD_TIMEOUT` | 下载超时 |
| `VIDEO_UNAVAILABLE` | 视频不存在、不可访问或受外部站点限制 |
| `EMPTY_DOWNLOAD` | 适配器声称成功但没有产生非空媒体文件 |
| `DOWNLOAD_FAILED` | 其他已脱敏的下载失败 |

## 6. 组件接口

```python
def extract_douyin_url(share_text: str) -> str: ...

@dataclass(frozen=True, slots=True)
class DownloadResult:
    video_id: str
    title: str
    output_path: Path
    bytes: int

class DownloadAdapter(Protocol):
    def download(self, url: str, output_dir: Path, cookie_file: Path | None) -> DownloadResult: ...
```

CLI 只负责编排输入、调用服务并序列化结果；站点细节集中在下载适配器。首版使用 `yt-dlp`，自动化测试使用假适配器，不访问抖音。

## 7. 自动化测试

- 单元测试：无链接、多链接、协议、域名边界和合法短链。
- 服务测试：假适配器成功、超时、不可用、零字节文件和临时文件清理。
- CLI 测试：稳定 JSON、退出码、成功输出和失败脱敏。
- 安全测试：Cookie 内容不得出现在 stdout、stderr、异常或测试证据。
- 默认测试不得访问真实抖音；真实分享链接只用于可选冒烟。

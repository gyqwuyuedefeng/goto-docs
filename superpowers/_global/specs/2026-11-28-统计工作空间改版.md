# 统计工作空间改版

统计首页提供上传数据和预处理两个入口。预处理按钮显示功能暂未开放。工作空间用卡片显示数据集，可自定义名称。类型确认页分页展示作者提供的变量信息，勾选移除的是变量，原始上传及已受理的统计快照仍可用于各自的流程。有序类别支持拖拽，键盘可在同一列表完成调序。再次编辑在独立版本保存，账号权限、配额和过期规则适用于每个版本。

统计方法页选用工作空间数据，数据概况提供变量角色编辑并统计各角色的变量列数。角色按方法校验，分析时保存实际分组、变量和 ID 选项。统计方法计算请求只使用已就绪的个人数据集。单样本的逐变量假设表作为方法的辅助参数沿用其校验。

新版产物约定为 base/data.RData 和 base/variable_info.xlsx，预处理产物使用 preprocessing 子目录。本地 gotoStat 0.1.0 的确认接口产生旧文件名，结构化摘要为空，且现有描述性统计调用无法直接读取确认产生的 RData。先以现有版本的统计适配方式完成可运行闭环，把未验证的新版 R 直传作为待验收项。

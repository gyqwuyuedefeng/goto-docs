# 桑基图节点数据自动生成与参数联动实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用户保存桑基图边数据标记后，由 `task` 服务异步调用 R 自动生成并刷新节点数据，同时完成节点层级、标签对齐和边填充色的前端联动。

**Architecture:** `goto-system` 在保存边标记后向现有 CommonTask Redis Stream 发布任务；`goto-task` 使用专用 Handler 和 Stage 调用 `gotoPlot::get_nodeslist_from_edges`、后处理节点文件并更新 UserDraw；通知经现有 Redis Stream 和 WebSocket 返回 `goto-web`。前端复用普通上传完成后的状态与参数联动入口，节点上传卡片隐藏但结果页签保留。

**Tech Stack:** Java 17、Spring Boot、Spring Data JPA、Redis Stream、Rserve、JUnit 5、Mockito、Vue 2、Jest、Playwright、MySQL 8

核心接口固定为：

```java
public Map<String, Object> publishAfterEdgeMarkSaved(PlotType resources) {
    if (!isSankeyEdgeMarkSave(resources)) {
        return Collections.emptyMap();
    }

    Long currentUserId = SecurityUtils.getCurrentUserId();
    UserDraw stored = userDrawRepository.findByIdAndUserId(
        resources.getUserDraw().getId(), currentUserId);
    if (stored == null) {
        throw new BadRequestException("用户绘图不存在或无权访问");
    }

    ChartUploadFileSettings nodes = requireFileSetting(stored, 1, "nodesFile");
    String javaRoot = PlotTypeUtils.obtainUserDrawPath(componentBean, stored);
    String rRoot = PlotTypeUtils.obtainUserDrawPathForR(componentBean, stored);

    SankeyNodeGenerateTask data = buildTaskData(stored, resources, nodes, javaRoot, rRoot);
    CommonTask<SankeyNodeGenerateTask> task = new CommonTask<>();
    task.setTaskType(TaskType.SANKEY_NODE_GENERATE.getType());
    task.setData(data);
    task.setCommonNoticeUUID(requireNoticeUuid(resources.getCommonNoticeUUID()));
    task.setUser(((JwtUserDto) SecurityUtils.getCurrentUser()).getUser());
    task.setStatusChange(false);
    CommonTaskStreamPublisher.publish(componentBean, task);

    return Map.of("submitted", true, "taskId", task.getCommonNoticeUUID());
}
```

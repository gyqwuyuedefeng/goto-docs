## 配置核对与方案

只读查询 `app_plot_group` 得到热图 ID=13；查询 `app_plot_type` 的模板 ID=1，并核对 `sys_dict`、`sys_dict_detail`。
模板参数由 `{type,param}` 序列化列表构成，运行时反序列化成 `topParamSettingsList/paramSettingsList`。

| 条件 | 行为 |
| --- | --- |
| 任意热图样式 | 单元格设置始终显示，删除旧上/下三角 Tab 联动 |
| dataset 的 value 标记恰好两列 | cellOverlay 显示 |
| 两列值或 heatmapStyle=split | 单元格设置2 显示，否则隐藏 |
| showNumberA/B=FALSE | numberDigitsA/B、numberFontA/B 隐藏；TRUE 恢复 |
| defaultCluster/colCluster/rowCluster=FALSE | 对应分组内开关之后的参数隐藏；TRUE 恢复 |
| 注释条配置来源存在有效标记 | labelRelPos 显示；两侧均无有效来源则隐藏 |
| heatmapStyle=triangle/invtriangle | colLabelPos、rowLabelPos、colLabel、rowLabel 隐藏，leftLabel/rightLabel 显示 |
| 其他热图样式 | 上述四项显示，leftLabel/rightLabel 隐藏 |
| 行列变量集合不一致 | 样式回退 full，其余选项禁用；diagonal 隐藏；共用聚类 Tab 隐藏，独立行列聚类 Tab 显示 |

字典 62 的样式值为 full/upper/lower/triangle/invtriangle/split；83 为 diag_main/diag_anti/marker_overlay；74 为 inside/outside。布尔组件值使用 TRUE/FALSE。
file_settings 中 dataset 的 value 标记使用 positionParam 位，不能用数值列数量或参数颜色 BY 列代替；注释条来源复用现有 byFileMarkColumnList 解析，不重新解释或改写来源配置。

选择扩展热图现有刷新函数和文件生命周期注册，复用公共布尔解析和参数查询。另一方案是在各 Vue 控件分散添加热图条件，会重复状态判断且难以覆盖首次加载，因此不采用。数据库模板不承担前端交互限制，不执行数据库写入。

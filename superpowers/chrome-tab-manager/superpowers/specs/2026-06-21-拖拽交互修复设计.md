# 拖拽交互修复设计

**日期：** 2026-06-21

## 问题

1. 子分组无法从父分组中拖出到根级
2. 同级分组无法拖拽调整顺序
3. 网页跨分组拖拽时部分场景失效

## 根因

- `treeRoot` 无 `dragover`/`drop` 事件，分组无法拖出到根级
- `attachGroupDrag` 的 `drop` 只处理"成为子分组"，不支持同级排序
- 网页拖到分组上时，分组 events 可能被子元素阻挡

## 方案：鼠标位置三分区

| 鼠标 Y 位置 | 高亮效果 | 操作 |
|---|---|---|
| 上 1/3 | 目标顶部蓝色插入线 | 排到目标**前面**（同级） |
| 中 1/3 | 目标整体高亮 | 成为目标**子分组** |
| 下 1/3 | 目标底部蓝色插入线 | 排到目标**后面**（同级） |
| treeRoot 空白 | treeRoot 蓝色虚线边框 | 移到根级对应位置 |

## 变更文件

| 文件 | 变更 |
|---|---|
| `src/sidepanel/sidepanel.js` | `attachGroupDrag` 增加三分区检测和索引计算；`treeRoot` 增加 drop 支持；网页拖拽增加 `dragover` 到 treeRoot |
| `src/sidepanel/sidepanel.css` | 新增 `.drag-insert-top` `.drag-insert-bottom` 蓝色插入线样式；`.drag-over-child` 子分组高亮样式 |

## 边界

- 防循环检测不变
- 拖到自身时忽略
- 连续快速拖拽时的状态刷新
- 深色主题下插入线颜色适配

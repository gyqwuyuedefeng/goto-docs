# 热图来源配置保存返修

用户已确认设计并要求继续，在当前会话执行，沿用原任务变更集。

目标：PlotGroup 的分类集合来源选择保存后能回显，随后由用户执行既有同步操作。

已复现根因：`MarkColumnSelector` 的 `@modify="modify(setting)"` 将没有 params 的管理端配置事件送入热图行列回调；读取 `params.optionName` 抛异常，阻止 bus 重建持久化 paramSettings。

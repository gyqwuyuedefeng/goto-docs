# 通用任务通知简化与工具下载兜底 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `hybrid-subagent-driven-development` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复通用任务 Redis Stream 通知在 `data` 反序列化为 `Map` 时无法生成工具下载 `taskId` 的问题，并为图片/Excel 转换前端增加下载兜底。

**Architecture:** 当前 Codex 会话作为 controller、reviewer、planner 和用户决策入口；DeepSeek 通过 `codex-dp-exec` 在隔离 worktree 中按任务实现。`goto/common` 统一修复 `CommonTask.simpleData()` 的 Map 兜底，`goto-web` 在图片转换和 Excel 转换页面保存提交响应中的 `taskId` 并在成功通知缺少 `taskId` 时兜底。

**Tech Stack:** Java 17, Spring Boot 3.3.4, Maven 3.6.3, JUnit 5, Vue 2, Element UI 2, ESLint, Redis Stream, codex-dp-exec.

```text
CommonTask.commonNoticeUUID
  含义：前端页面通知路由，也是图片/Excel/拼图等工具下载任务 ID。

BasicMessage.data
  成功通知给前端的数据体。
```

Why This Task Exists:

`CommonTask.simpleData()` is the common exit point that `system` uses before WebSocket push. After Redis Stream deserialization, `CommonTask.data` can be a `Map`; current `instanceof` checks fail and raw task payload reaches the frontend without `taskId`. This task fixes the backend root cause and keeps `taskId = commonNoticeUUID`.

Existing Context:

- Approved spec requires Map fallback for `FILE_RESHAPE`, `IMAGE_CONVERT`, and `MERGE_IMAGE`.
- `TaskType.FILE_RESHAPE` is `11`, `IMAGE_CONVERT` is `12`, `MERGE_IMAGE` is `13`.
- Existing DTO branches in `CommonTask.simpleData()` must continue to work.
- `ImageConvertTask.fileName` may contain an R output path. This task does not solve path semantics; it preserves current behavior and only ensures `taskId` and known fields are present.

Required Implementation Steps:

- [ ] Add a focused helper inside `CommonTask` to detect `data instanceof Map`.
- [ ] For `taskType = TaskType.FILE_RESHAPE.getType()`, return a new `Map<String, Object>` with:
  - `taskId = this.commonNoticeUUID`
  - `fileName = dataMap.get("fileName")`
  - `type = dataMap.get("type")`
  - `status = basicMessage.getStatus()`
- [ ] For `taskType = TaskType.IMAGE_CONVERT.getType()`, return a new `Map<String, Object>` with:
  - `taskId = this.commonNoticeUUID`
  - `fileName = dataMap.get("fileName")`
  - `inputFormat = dataMap.get("inputFormat")`
  - `outputFormat = dataMap.get("outputFormat")`
  - `status = basicMessage.getStatus()`
- [ ] For `taskType = TaskType.MERGE_IMAGE.getType()`, return a new `Map<String, Object>` with:
  - `taskId = this.commonNoticeUUID`
  - `fileName = dataMap.get("archiveFileName")`; if blank or null, fallback to `dataMap.get("fileName")`
  - `status = basicMessage.getStatus()`
- [ ] Leave existing DTO `instanceof` branches intact for non-Map data.
- [ ] Unknown task types with `Map` data should preserve existing behavior by returning raw `data`.
- [ ] Add `CommonTaskSimpleDataTest` with detailed Chinese class and method comments.

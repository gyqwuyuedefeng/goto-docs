# 多级分组树形结构设计

> 基于方案 B（统一 children 数组 + 内联网页），将当前平级分组升级为无限层级树形分组结构。

**创建日期：** 2026-06-21

---

## 一、目标

- 分组支持无限层级嵌套，`parentId` 定义父子关系
- 分组可同时包含网页和子分组，按 `sortOrder` 混排
- 网页内联存储在分组的 `children` 数组中（非引用）
- 支持拖拽分组成为另一个分组的子分组
- 支持拖拽网页在任意分组间移动
- 旧导出数据兼容（自动补齐 `parentId: null`、`children` 数组）

---

## 二、数据结构

```js
state = {
  ui: { mode, collapsed, navWidth, theme },
  groups: [
    {
      id: 'g1',
      name: '智能体',
      parentId: null,          // null = 根级分组
      sortOrder: 1,            // 同级排序序号
      expanded: true,
      pinned: false,
      createdAt: '...',
      updatedAt: '...',
      children: [
        // 网页（内联全部字段）
        { kind: 'item', id: 'i1', title: 'Rancher', url: 'https://...',
          source: 'page', favorite: false,
          faviconUrl: 'https://.../favicon.ico', createdAt: '...' },
        // 子分组（引用 groupId，防止循环）
        { kind: 'group', groupId: 'g2' },
        { kind: 'group', groupId: 'g3' },
        { kind: 'item', id: 'i2', title: 'Grafana', url: 'https://...',
          source: 'page', favorite: false,
          faviconUrl: 'https://.../favicon.ico', createdAt: '...' },
      ]
    },
    {
      id: 'g2',
      name: '金融端-生产',
      parentId: 'g1',
      sortOrder: 2,
      expanded: true,
      pinned: false,
      children: [
        { kind: 'item', id: 'i3', title: '后台管理', url: '...',
          source: 'page', favorite: false,
          faviconUrl: '...', createdAt: '...' },
      ]
    },
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `group.parentId` | `string \| null` | 父分组 ID，`null` 为根级 |
| `group.children` | `array` | 子内容数组，按 sortOrder 混排网页和子分组引用 |
| `child.kind` | `'item' \| 'group'` | 条目类型：网页或子分组 |
| `child.groupId` | `string` | 子分组引用（kind=group 时），指向某个 group.id |
| 网页字段 | — | `id, title, url, source, favorite, faviconUrl, createdAt` 全部内联 |

### 约束

- `children` 数组位置即排序，不再需要网页级别的独立 `sortOrder`
- 同一父分组内不允许重复 URL
- 子分组引用 `groupId` 必须对应已存在的 `group.id`
- 拖拽时禁止将分组拖入自己或自己的后代分组（防循环）

## 三、渲染逻辑

### 树形列表

从 `parentId === null` 的根级分组开始递归渲染：

1. 渲染分组头（名称、折叠/展开、菜单按钮）
2. 遍历分组 `children` 数组
3. `kind: 'item'` → 渲染网页行（favicon、标题、域名、菜单按钮）
4. `kind: 'group'` → 按 `groupId` 找到子分组，递归渲染
5. 每层缩进 16px，通过 CSS `padding-left` 控制

### 搜索过滤

- 匹配分组名、网页标题、域名、URL
- 匹配到的子分组连带其祖先自动展开显示
- 不匹配的分支折叠隐藏

### 图标墙

- 按分组分区显示，分区标题显示路径（如"智能体 / 金融端-生产"）
- 展开的分组才显示其内部网页卡片
- 常用网页在顶部"常用"区独立显示，标注所属路径
- 折叠的子分组在图标墙中不展开其内部网页

### 折叠态

- 全部展开为扁平 icon 列表，忽略树形结构
- 优先显示常用网页
- 分组本身的恢复等操作通过 `⋯` 菜单，折叠态不减功能

## 四、拖拽行为

### 数据操作层面

所有排序通过 `children` 数组的 splice + 重排实现：

| 操作 | 实现 |
|---|---|
| 网页 A 移到分组 B | 从 A 原分组的 children 删除 → 追加到 B 的 children |
| 分区内调整顺序 | 在原分组的 children 中移动位置 |
| 分组 A 成为分组 B 的子分组 | 改 A 的 `parentId = B.id` → 在 B 的 children 末尾插入 `{kind:'group', groupId: A.id}` |
| 同级分组排序 | 在父分组的 children 中调整 group 条目的位置 |

### 防循环检测

拖拽分组到目标位置前，检查目标是否是当前分组或其后代：
```js
function isDescendant(groups, ancestorId, targetId) {
  if (ancestorId === targetId) return true;
  const target = groups.find(g => g.id === targetId);
  if (!target || !target.parentId) return false;
  return isDescendant(groups, ancestorId, target.parentId);
}
```

### 交互

- 网页行/分组头 `draggable="true"`
- `dragover` 高亮目标分组
- `drop` 执行移动逻辑，持久化后重渲染

- "移动到分组"改为弹出一个扁平分组列表选择器（含路径），选中后移动网页

## 六、数据迁移

### normalizeState 兼容

旧数据自动补齐：

```js
groups: groups.map(g => ({
  ...g,
  parentId: g.parentId || null,
  children: g.children || g.items.map((item, i) => ({
    kind: 'item',
    ...item,
    sortOrder: undefined  // 移除旧字段
  }))
}))
```

### 导出/导入

- 导出 JSON 格式与新结构一致
- 导入时走 `normalizeState`，旧格式 JSON 自动转换
- `parentId: null` 的分组排在顶层

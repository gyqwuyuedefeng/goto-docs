# 热图矩阵识别与注释参数返修实施计划

> 使用 Superpowers 的测试先行流程，在当前隔离工作区逐项实施。

**目标：** 让热图使用 R 的检测结果控制参数，并将两侧注释颜色和图例完整传给绘图链路。

**结构：** goto/system 提供受权限保护的检测接口；goto-web 只维护界面派生状态和隐藏绘图参数；goto/common 修复现有参数生成器的空值分支。

**技术栈：** Java 17、Spring、Rserve、Vue 2、Jest、Maven。

## 任务

- [x] 为 `goto/common/src/main/java/com/freedom/util/PlotTypeUtils.java` 增加失败测试：`ClassifyParamList.value=null` 且 `list` 非空时必须输出 R 列表；修复空值提前返回并重跑测试。
- [x] 为 `goto/system` 增加失败测试：只接受热图、本人绘图或模板示例、已保存的数据集和单选 `x_column/y_column/value`；R 返回值只接受布尔及已知数据类型；然后实现检测接口与 API。
- [x] 为 `goto-web/src/constant/modify/heatmapModify.js` 增加失败测试：检测结果替换旧集合判断；覆盖四种对称/次值组合、当前布局名、两组 Tab、单元格布局及聚类参数；然后实施最小改动。
- [x] 为 `goto-web/src/constant/classifyLegendRefresh.js` 增加失败测试：热图注释的嵌套 7 进入图例列表；异步重建后刷新；然后实施。

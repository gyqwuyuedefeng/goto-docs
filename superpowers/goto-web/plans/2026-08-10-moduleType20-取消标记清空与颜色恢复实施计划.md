# moduleType=20 取消标记清空与颜色恢复实施计划

> **面向 Agent 执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 按任务实施本计划。所有步骤使用复选框跟踪。

**目标：** 取消 moduleType=20 关联的文件标记并保存后清空当前分面参数，同时在将来重新标记并主动勾选同一列时恢复原背景色和边框色。

**架构：** 在现有 `facetColorStateCache` 边界内增加“重置前颜色快照”入口；在 `paramSettingsReset.js` 中把关联解析结果细分为关联缺失、明确为空和存在有效标记。活动列表只反映当前标记，颜色缓存继续按 `columnName + fileSettingIndex` 保留可恢复状态。

**技术栈：** Vue 2.6、JavaScript、Jest 23、Vue 2 `$set` 响应式更新、JavaScript `WeakMap`。

## 全局约束

- 不改变 `facetFileMarkColumnList` 本身的组件关联配置。
- 不持久化运行时颜色缓存，缓存不得进入 moduleType=20 设置对象或后端序列化数据。
- 不恢复旧版“每次都先全量清空再重建”的实现。
- 不修改 moduleType=7、22、27 或刻度范围等其他参数类型的重置语义。
- 不重构现有分面组件，不建立新的通用状态管理层。
- 重新标记同一列后默认不恢复旧勾选；只有用户主动勾选时才恢复背景色和边框色。
- 跨文件同名列必须继续按 `fileSettingIndex` 隔离。
- 工作区已有改动属于用户；每次提交只暂存本任务明确列出的文件。
- 相关测试基线已有 Browserslist 过期提示和历史 `console.log` 输出；本次不得新增警告或日志噪声，不把清理历史输出扩大到当前修复范围。

- [ ] **Step 5：实现关联源解析状态**

用以下函数替换只返回数组的 `collectFacetHeaderInfos()`：

```js
/**
 * 解析分面关联标记，并区分“关联源不可用”和“关联源存在但当前未选择”。
 * 只有文件、表头数组、SELECT_COLUMN 容器和位置信息均存在时，才认为关联源可解析。
 *
 * @param {Object} commonParams 公共参数
 * @param {Array} markColumns 分面关联标记列表
 * @returns {{bindingResolved: boolean, headerInfos: Array}}
 */
function resolveFacetHeaderInfoState(commonParams, markColumns) {
  const headerInfos = []
  const seen = new Set()
  let resolvedBindingCount = 0
  const fileSettings = commonParams && commonParams.fileSettings

  if (!Array.isArray(fileSettings)) {
    return { bindingResolved: false, headerInfos }
  }

  ;(markColumns || []).forEach(markColumn => {
    if (
      !markColumn ||
      !Number.isInteger(markColumn.fileSettingIndex) ||
      markColumn.fileSettingIndex < 0
    ) {
      return
    }

    const fileSetting = fileSettings[markColumn.fileSettingIndex]
    if (!fileSetting || !Array.isArray(fileSetting.headerInfoList)) return

    const markContainer = findMarkContainer(fileSetting, markColumn.filedName)
    if (!markContainer || !Number.isInteger(markContainer.positionParam)) return

    resolvedBindingCount += 1
    resolveHeaderInfosForMarkColumn(commonParams, markColumn)
      .forEach(headerInfo => {
        const key = buildFacetColumnKey(
          headerInfo.columnName,
          headerInfo.fileSettingIndex
        )
        if (seen.has(key)) return
        seen.add(key)
        headerInfos.push(headerInfo)
      })
  })

  return {
    bindingResolved: resolvedBindingCount > 0,
    headerInfos
  }
}
```

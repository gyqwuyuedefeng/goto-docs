# 图形通用数据与辅助线实施计划

绘图工作台共用 Excel 选择与上传流程。换表后按参数与新数据的实际关系保留有效设置。本轮沿用已经部署的辅助线契约，换数据时校验已有辅助线。用户同意在查不到新 R 列表入参时暂缓新的多行编辑器。

## 开发基线

2026-11-23 通过 Windows Git 获取 `goto-web` 的 `origin/master`，确认 SHA 为 `95d476d099eb0d3565ccd981ce20bd59e7b67d7c`。本地 `master` 包含该 SHA，且 `6c0e199ff822e12cc8a302718a135a96a9dcd90d` 已有正式发布记录。从该提交建立 `feat/048-图形通用数据与辅助线`。

现行折线图模板 241 和散点图模板使用旧的 `hLine`、`vLine`、`bLine` 六项参数和值样式。线型使用字典 21 `gs_line_type`，值为 1 至 6。绘图 R 命令在 `goto/common` 的 `PlotTypeUtils.autoCreateParam` 生成，由 task 调用。列表入参需要从正常绘图接口验证；四个机密 R 包只通过已安装服务执行业务验收。

# 桑基图刷新首帧稳定性设计

## 当前阶段与目标

用户已确认采用“生成 iframe 内容之前预置隐藏按钮和居中样式”的方案。本文件供书面设计审阅；实现、修复后验收、合并与部署尚未执行。

目标：刷新或重新进入已有桑基图结果时，从第一帧起不出现内部绿色 Download SVG 按钮；图形出现时即在结果区域居中，不经历靠左后跳到中间的过程。保留现有节点拖拽、页签切换和统一下载能力。

## 已确认的现象和原因

2026-10-20，在 goto-web 提交 7cac1834e02e286fa34b19988cc6d6128ff17f61 上，使用当前前端和历史真实生成的桑基图 HTML 回放。后端接口为模拟数据，不代表当前线上记录或新一轮 R 计算验收。

- 三次缓存脚本刷新都记录到按钮可见、body 为 block、SVG 左边距约 8px 的加载状态；SVG 中心相对 iframe 中心偏左约 237px。
- iframe 的 load 回调之后，按钮才隐藏，body 才成为居中的 Flex 容器，中心偏差归零。
- 将外部脚本请求分别延迟 1000ms、1500ms 后，初始错误状态持续约 1.5 秒，与用户补充截图中的按钮闪现相符。
- PlotResultCanvas.vue 的 createIframeContent 直接用原 HTML 创建 Blob；隐藏按钮、设置 body/html 居中样式均发生在 iframeLoaded 中。浏览器可在 load 之前绘制 HTML，所以仅在 load 中处理已经太晚。
- 既有浏览器用例检查最终下载按钮不可见，不能证明加载过程从未闪现。

诊断服务使用本次独立端口 42140，结束后已经 Ctrl-C 关闭并确认端口释放，前端工作区保持干净。

## 对象与范围

本次修复对象为 HTML 结果的桑基图，前端判断复用 isSankeyHtmlResult。2026-10-20 只读实查确认图形组为 15（桑基图，组 show=0），模板 120、182、183、240、288 的 status/show 均为 1；120 为本次调查样本。组级隐藏不改变已存在结果的加载机制。

样本 120 的可见参数分组为“预览与输出、节点设置、边设置、标签设置、图例设置、标题/副标题、主题样式”，“管理参数”隐藏；文件为 edgesFile、nodesFile。按钮和整图居中属于结果展示层，不由这些参数分组、数据字典、列标记或节点内部对齐参数控制，本次不调整其语义。

预期生产代码仅触及 goto-web 的 PlotResultCanvas.vue 及必要的局部处理方法。新增或调整验证沿用现有 unit 与 e2e 目录。网络图、静态图片、后端协议、数据库模板、外部脚本和 R 包均不在修改范围；禁止读取或修改四个机密 R 包源码。

## 方案比较

采用：生成 Blob 之前预置样式。直接消除错误样式的可见窗口，不新增显示状态，也保留 iframe 的正常布局尺寸，适合本次两个现象的共同原因。

不采用：先隐藏整个 iframe，load 后再显示。虽然可遮住中间画面，但需要额外处理显示时机和失败恢复；若误用 display:none，还会触发已有隐藏页零尺寸重排问题。当前已有更小的修复路径。

不采用固定等待时间或仅提前调用一次隐藏按钮函数：外部资源耗时不固定，且子文档尚未创建时调用不能约束后续首帧。

## 处理流程与样式

1. createIframeContent 保持原有来源绑定和就绪失效流程。仅在当前结果为 HTML 桑基图且 HTML 非空时，对局部 HTML 副本进行样式预置。
2. 使用浏览器原生 HTML 解析能力创建独立文档，在 head 中加入一段本次专用的内联样式，再序列化为用于 Blob 的 HTML；不执行其中的脚本。
3. html/body 从文档首次排版起具备 100% 高度、零 margin/padding；body 使用 display:flex、align-items:center、justify-content:center，取值与现有 iframeLoaded 一致。
4. #download-svg 和 .download-buttons 使用 display:none !important，让 HTML 内置下载控件在解析到节点时即被隐藏。只影响 iframe 内部控件。
5. 原有脚本、外部资源地址和加载顺序、节点及连线数据、SVG 属性、标题、图例、交互补丁均保留；保留有效文档类型，不把脚本或业务数据重新生成一份。
6. 使用预置样式后的副本创建 Blob。原始 plot.userDraw.html 不回写、不持久化、不作为新的来源标识，来源匹配继续使用原有记录和原始 HTML。
7. iframeLoaded 仍执行高度计算、居中样式及隐藏按钮的兜底处理，随后进行当前 Blob/来源就绪确认和有效 SVG 采集。预置样式不会提前把结果标记为可导出。

iframe 继续参与正常尺寸计算，不新增 display:none、v-if 加载闸门或第二套就绪状态。高度更新前后都采用相同居中规则；浏览器验收必须同时确认全局画面没有水平或垂直跳动。

网络图及其他结果按原路径处理，HTML 字符串不经过本次转换。

## 异常与既有行为

- HTML 为空时沿用当前静态结果或无结果分支，不制造带样式的假 HTML。
- 外部脚本延迟或失败时，下载按钮仍由首屏内联样式隐藏；不新增超时、自动重试或隐藏后永久不显示的状态。
- 导出仍须通过现有当前来源、文档 URL、有效 SVG 和正尺寸检查。样式预置成功不等于绘图成功，也不能用旧记录快照补充缺失结果。
- 本次不改变脚本失败提示和回退策略；若实施中发现预处理会破坏有效 HTML 或脚本语义，须先修正转换方式，不能以展示未经处理的原内容掩盖验收失败。

沿用项目 e2e 目录保存可重复执行的首帧回归，实际生成的业务 HTML 通过运行时路径输入，不把其完整脚本和业务数据固化进仓库；截图、逐帧数据等写入本次临时目录。使用本次独立启动的前端及动态端口，reuseExistingServer=false。

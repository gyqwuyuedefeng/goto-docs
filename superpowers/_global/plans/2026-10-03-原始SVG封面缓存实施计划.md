# 原始 SVG 封面缓存实施计划

> 执行方式：使用 superpowers:subagent-driven-development 逐任务实施与评审；前后端契约确定后在不同仓库并行实现。

**目标：** 原图跨刷新条件缓存、封面队列持续排空及资料更新后正确失效。

**架构：** 原始 SVG GET 由当前权限控制，浏览器私有缓存自动复验；前端 Blob/ObjectURL 按需展示；保留旧 POST。相关资料缓存在事务提交后更新并完整替换。

**技术栈：** Java 17、Spring Boot 3.3.4、Redis/Redisson、Vue 2、Axios 0.21、Jest、Playwright。

## 全局约束

- 仅使用原始 SVG，不生成缩略图，不修改原图内容。
- 接口固定为 `GET /api/plot/group_preview/{groupId}/{typeId}`；权限沿用 `plot:group_list`。
- 成功响应 `private, no-cache` 与内容摘要 ETag；鉴权和显隐检查先于 304；非图片成功响应 no-store。
- 队列并发 4；预加载范围 240px；单次超时 15000ms；暂时性故障自动重试一次。
- 旧批量 POST 保持可用；不新增图片 Redis 缓存、CDN 或 IndexedDB 封面协议。
- gotoTools、gotoBase、gotoPlot、gotoStat 及同源副本禁止读取、搜索、索引。
- Java 与测试必须有解释业务意图的中文注释，所有提交携带当前 Change-Set-Id。
- Maven 仅使用 WSL 安全包装器；不复制共享 Maven 仓库到 worktree。真实登录采用 local/home 和项目登录恢复规则。

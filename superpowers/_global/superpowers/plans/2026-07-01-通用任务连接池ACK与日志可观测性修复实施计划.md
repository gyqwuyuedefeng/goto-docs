# 通用任务连接池 ACK 与日志可观测性修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development`, `hybrid-subagent-driven-development`, or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复通用任务在数据库连接池 stale idle 连接场景下的失败恢复、ACK 语义、日志降噪和手动 ACK 可观测性。

**Architecture:** 在 `goto/task` 固定 Job Ledger 创建失败不 ACK 的可靠性语义；在 `freedom-public` 的 Redis Stream starter 中让 manual ACK 日志区分 pending/completed；在 logging 模块把图片 base64 参数替换为结构化摘要；同步调整 task/system Hikari 配置，降低整池 stale 连接导致的短超时风险。

**Tech Stack:** Java 17, Spring Boot, JPA/Hibernate, HikariCP, Redisson Redis Stream, JUnit 5, Mockito, AssertJ, Maven.

- [ ] **Step 3: Implement the sanitizer**

Create `LogParameterSanitizer.java`:

```java
package com.freedom.service.impl;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

final class LogParameterSanitizer {

    private static final Pattern IMAGE_BASE64_DATA_URL = Pattern.compile(
            "data:image/([A-Za-z0-9.+-]+);base64,([A-Za-z0-9+/=\\r\\n]+)");

    private LogParameterSanitizer() {
    }

    static String omitImageBase64(String params) {
        if (params == null || params.isEmpty()) {
            return params;
        }
        Matcher matcher = IMAGE_BASE64_DATA_URL.matcher(params);
        StringBuffer result = new StringBuffer(params.length());
        while (matcher.find()) {
            String mediaType = matcher.group(1);
            String payload = matcher.group(2);
            String replacement = "data:image/" + mediaType
                    + ";base64,<omitted length=" + payload.length()
                    + " sha256=" + shortSha256(payload) + ">";
            matcher.appendReplacement(result, Matcher.quoteReplacement(replacement));
        }
        matcher.appendTail(result);
        return result.toString();
    }

    private static String shortSha256(String value) {
        try {
            MessageDigest digest = MessageDigest.getInstance("SHA-256");
            byte[] bytes = digest.digest(value.getBytes(StandardCharsets.UTF_8));
            StringBuilder hex = new StringBuilder(16);
            for (int i = 0; i < 8; i++) {
                hex.append(String.format("%02x", bytes[i]));
            }
            return hex.toString();
        } catch (NoSuchAlgorithmException e) {
            return "unavailable";
        }
    }
}
```
